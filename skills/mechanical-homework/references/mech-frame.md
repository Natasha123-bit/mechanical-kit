# 说明书插图四件套（mech_frame）：画法口径与实现要点

> 自 `mechanical-homework/SKILL.md` 下沉（2026-10-26），正文未改。

- `draw/mech_frame.py` —— 说明书插图四件套：`轴草图` / `力学模型` / `弯矩图` / `转矩图`，都返回外框方便上下叠放；自测 `draw/mech_frame_tests.py`（35 项）。模块 docstring 顶部是**画法口径清单 7 条**（每条注明出处：`图纸/输出轴零件图.py` 行号或用户口述），改图前先读它；测试逐条对应，不写新口径就别改图。要点：
  - 台阶面竖线**贯穿较大直径全高**（不是只连两个半径差）；只靠轮廓多边形的短竖边，⌀60→⌀70 这类 2 mm 差在 0.44 比例下不足 1 mm，等于没画。
  - 直径尺寸：尺寸线**贯穿整个直径**（`cy−r → cy+r`），上下两端箭头都**朝外顶住轮廓**；φ 值竖排写在尺寸线**左侧**、偏移 0.8 mm、上半区（避开中心线）。**尺寸线到箭头尖端为止，不越出轮廓**——越出的是尺寸界线，而直径尺寸的界线就是轮廓本身（只画到半径、或让尺寸线多出 2 mm 线头，都是错的）。**窄段也不用引线**：φ 值一律写在尺寸线上，挤就靠窄段上下交替错开（`side=±1`）与落点避让解决；自造「画箭头把 φ 拉出轮廓外横排」的标法没有国标依据，会被打回。**同一直径的连续段只标一次**（⌀60 连两段只出一个 ⌀60），按 `abs(d−d_prev)<1e-9` 合并段组后再标注。
  - 长度尺寸界线：起于轮廓外 0.5 mm，**越过尺寸线 2 mm**。写成 `max(y_edge-0.5, yy-2.0)` 会恒取轮廓端（`y_edge` 永远在 `yy` 上方），界线永远不越线。
  - 轴草图的 `齿顶圆` **默认关**——轴上另装的大齿轮 d_a 常是轴径 3~4 倍（⌀294 装 ⌀70），照实画会把整幅图撑爆，只在齿轮轴（齿轮与轴一体）时开，否则件号写「齿轮 4（d_a=294 见零件图）」。
  - 件号引线是「引杆 + 箭头」两段，只发箭头会悬空；落点自动避让 ⌀ 文字（压上就改指该段台阶）。**尺寸链数字写在尺寸线之上**（`yy+1.2`；写 `yy−3` 会掉到线下方），窄段交错分行，下部留白按「数字一行 + 交错一行 + 总长一行」预留。
  - 弯矩图默认按值符号画，`求拉侧="上"/"下"` 翻到受拉侧；用竖向细线填充（`gbdraw` 的 CSS 会盖掉 `fill` 属性）。
  - 出图前先定图幅高度（件号两档 + 尺寸链两档 + 总长共约 30 mm），否则标签被上沿切掉。
