## 2. 课程内容五部分（p.4 原文）

1. **总论部分**：机器及零件设计的基本要求、设计准则、设计方法、材料选择、结构要求、强度理论、摩擦磨损润滑等基本概念与知识。
2. **连接设计**：螺纹连接，键、花键及无键连接，销连接，铆接、焊接、胶接、过盈连接等。
3. **传动设计**：螺旋传动、带传动、链传动、齿轮传动、蜗杆传动、摩擦轮传动等。
4. **轴系设计**：滑动轴承、滚动轴承、联轴器与离合器、轴等。
5. **其他部分**：弹簧、机座和箱体、减速器和变速器等简介。

## 3. 关系清单

1. **机械工业 → 国民经济**：为各行业提供技术装备；其水平是国家现代化的重要标志。
2. **机器 → 做功**：传递/转换能量、物料、信息，代替体力与部分脑力劳动，提高生产率、改善劳动条件。
3. **机器 → 机械系统 → 机构 → 零件**：逐层分解；零件是基本组成要素。
4. **设计 → 创新**：设计活动是各项创新的起点和关键环节；机械设计理论为更高层次创新奠基。
5. **现代机器发展方向**：自动化、智能化、性能更高、与人更和谐；设计理论与自动化/信息/管理/生命/艺术等学科融合。
6. **课程性质 → 能力培养**：以通用零件设计为核心，训练设计思想、方法、标准/手册使用、试验技能与政策了解。
7. **先修课程 → 本课程 → 专业课程**：综合运用先修知识，经教学与实践环节过渡到专业产品/设备设计。
