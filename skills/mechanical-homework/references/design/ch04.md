## 2. 核心术语

### 摩擦（4-1）

| 术语 | 定义（原文/紧贴原文） | 页 |
|---|---|---|
| 摩擦 | 正压力下相互接触的两物体受切向外力影响发生相对运动或有相对运动趋势时，接触表面产生抵抗运动的阻力 | 50 |
| 摩擦学 | 研究摩擦、磨损与润滑的科学与技术 | 50 |
| 摩擦学设计 | 在机械设计中正确运用摩擦学知识，使零件具有良好摩擦学性能的过程 | 50 |
| 内摩擦 | 发生在物质内部、阻碍分子间相对运动的摩擦 | 50 |
| 外摩擦 | 相互接触两物体发生相对运动或有趋势时，接触表面产生的阻碍相对运动的摩擦 | 50 |
| 静摩擦 | 仅有相对运动趋势时的摩擦 | 50 |
| 动摩擦 | 相对运动进行中的摩擦（分滑动/滚动） | 50 |
| 干摩擦 | 两表面间无任何润滑剂或保护膜接触时的摩擦 | 50 |
| 边界摩擦（边界润滑） | 摩擦表面被吸附在表面的边界膜隔开，摩擦性质取决于边界膜和表面吸附性能 | 51 |
| 流体摩擦（流体润滑） | 摩擦表面被流体膜隔开，摩擦性质取决于流体内部分子间黏性阻力 | 51 |
| 混合摩擦（混合润滑） | 摩擦状态处于边界摩擦与流体摩擦的混合状态 | 51 |
| 膜厚比 λ | λ=h_min/√(Rq₁²+Rq₂²)，用于大致估计摩擦/润滑状态（式4-1） | 51 |
| 真实接触面积 A_r | 表面轮廓峰相接触形成的接触斑点微面积总和，远小于公称接触面积 A₀ | 51 |
| 边界膜 | 比较牢固地吸附在金属表面上的分子膜 | 52 |
| 吸附膜 | 按形成机理分为物理吸附膜与化学吸附膜 | 52 |
| 物理吸附膜 | 润滑剂中脂肪酸极性分子牢固吸附在金属表面形成 | 52 |
| 化学吸附膜 | 润滑剂分子受化学键力作用吸附在金属表面形成 | 52 |
| 反应膜 | 润滑剂中硫、氯、磷在较高温度（150~200℃）与金属反应形成的边界膜 | 53 |
| 薄膜润滑 | 介于流体润滑与边界润滑之间的过渡润滑 | 53 |

### 磨损（4-2）

| 术语 | 定义 | 页 |
|---|---|---|
| 磨损 | 两个接触表面相对运动过程中表面物质损失或产生残余变形 | 50 |
| 磨合阶段 | 包括摩擦表面轮廓峰形状变化与表面材料加工硬化两个过程 | 54 |
| 稳定磨损阶段 | 磨损速度平稳缓慢，摩擦条件相对恒定 | 54 |
| 剧烈磨损阶段 | 稳定磨损后表面破坏、间隙增大、出现额外动载荷、噪声与振动 | 55 |
| 黏着磨损 | 轮廓峰相互作用点“冷焊”后，相对滑动时材料从一个表面迁移到另一个表面 | 55 |
| 磨料磨损 | 外部游离硬颗粒或硬轮廓峰尖在较软材料表面犁创出沟纹 | 55 |
| 疲劳磨损 | 摩擦表面材料微体积在重复变形时疲劳破坏引起的机械磨损 | 55 |
| 流体磨料磨损 | 流动液体/气体中夹带的硬质物体或颗粒作用引起 | 55 |
| 流体侵蚀磨损 | 液流或气流冲蚀作用引起 | 55 |
| 机械化学磨损 | 机械作用与材料/环境化学或电化学作用共同引起 | 55 |
| 微动磨损 | 由黏着、磨料、机械化学和疲劳磨损共同形成的复合磨损 | 56 |

## 5. 关系清单

1. **摩擦状态谱**：干摩擦 → 边界摩擦 → 混合摩擦 → 流体摩擦；判据用膜厚比 λ（≤1 / 1~3 / >3）。
2. **边界膜**：吸附膜（物理/化学）与反应膜；温度升高时物理吸附膜失效、反应膜起作用。
3. **磨损三阶段**：磨合 → 稳定磨损 → 剧烈磨损；设计应缩短磨合、延长稳定、避免剧烈。
4. **磨损类型**：黏着、磨料、疲劳、流体磨料、流体侵蚀、机械化学、微动（复合）。
5. **黏度体系**：动力黏度 η（Pa·s）↔ 运动黏度 ν=η/ρ（m²/s）↔ 条件黏度 °E_t（式4-5）；牌号按 40℃ 中心值。
6. **黏-温/黏-压**：温度升高黏度下降（黏度指数越大越平缓）；压力升高黏度上升（式4-6）。
7. **润滑方式**：滴油、油环、浸油、飞溅、压力循环、脂润滑；按速度/载荷/结构选。
8. **流体润滑三类型**：流体动力（相对运动自生膜）、弹性流体动力（弹变+动压）、流体静力（外部泵压）。
