## 5. 关系清单（机器—设计—零件）

1. **机器组成**：原动机部分 → 传动部分 → 执行部分（基本组成，图2-1 双线框）；辅助系统、测控系统为附加组成（单线框）。
2. **设计程序**：计划阶段（设计任务书）→ 方案设计阶段（原理图/机构运动简图）→ 技术设计阶段（总装配草图、部件草图、零件图）→ 技术文件编制阶段（计算说明书、使用说明书、标准件明细表）。
3. **方案评价**：机器功能分析 → 评价；不可行返回上一步，可行则决策选定方案。
4. **失效—准则—方法**：整体断裂/残余变形 → 强度准则；过大弹性变形 → 刚度准则；表面破坏（腐蚀/磨损/接触疲劳）→ 寿命准则；振动 → 振动稳定性准则；随机失效 → 可靠性准则。
5. **设计方法**：理论设计（设计计算/校核计算）、经验设计、模型试验设计；现代设计方法含 CAD、优化、可靠性、并行、数字孪生、参数化、智能、分形、网络化设计。
6. **零件设计步骤**：选类型结构 → 算载荷 → 选材料/热处理 → 定尺寸 → 校核 → 画图 → 编技术文件。
