## 解题步骤 —— 蜗杆传动，与齿轮不同

> 公式库 `mdkit/lib/design/worm_ch11.py`（唯一版本）。逐式/逐表清单、例11-1 对比与抽查证据见本文件下文。例11-1（p.282–284）是范式。

1. **选类型/材料/精度**：动力传动常用 ZI（渐开线）或 ZA；蜗杆 45 钢淬火 45~55 HRC（高速重载可 20Cr 渗碳），蜗轮 10-1 锡青铜 ZCuSn10P1 金属模（配 >45 HRC 蜗杆，表11-7 取 268 MPa）；低速轻载可用灰铸铁/铝青铜。精度按 GB/T 10089—2018，例11-1 取 8 级。
2. **估效率、算 T₂**：按 z₁=1/2/4/6 估 η=0.7/0.8/0.9/0.95；T₂=9.55×10⁶Pη/(n₁/i)（p.283 写法）。
3. **定 K**：K=K_A K_β K_v；K_A 查表11-5（工作类型 II → 1.15）；平稳载荷 K_β=1，冲击 1.3~1.6；v₂≤3 m/s 取 K_v=1.0~1.1，>3 m/s 取 1.1~1.2。
4. **定 z₂、[σ_H]**：z₂=i z₁；锡青铜 [σ_H′] 查表11-7（材料/铸造/蜗杆硬度列），N=60jn₂L_h，K_HN=⁸√(10⁷/N)，[σ_H]=K_HN[σ_H′]；灰铸铁/高强度青铜直接查表11-6（不计 N）。
5. **按接触强度设计**：m²d₁≥KT₂(480/(z₂[σ_H]))²（式11-10）；按 z₁ 在表11-1 中取 m²d₁ ≥ 设计值的**最小标准行**，得 m、d₁。
6. **几何尺寸**：d₂=mz₂；a=(d₁+d₂)/2；d_a1=d₁+2h_a*m；d_f1=d₁−2(h_a*+c*)m；d_a2=d₂+2m(h_a*+x₂)；d_f2=d₂−2m(h_a*−x₂+c*)；r_g2=a−d_a2/2；γ=arctan(z₁/q)；p_a=πm；s_a=πm/2。例11-1 由尺寸反推 h_a*=1、c*=0.2。
7. **弯曲校核**：z_v2=z₂/cos³γ；Y_Fa2 查表11-8（按 z_v2 内插）；Y_β=1−γ/140°；[σ_F′] 查表11-9（单侧/双侧），K_FN=⁹√(10⁶/N)，[σ_F]=[σ_F′]K_FN；σ_F=1.53KT₂Y_Fa2Y_β/(d₁d₂m)≤[σ_F]（式11-11）。
8. **效率与热平衡**：v_s=πd₁n₁/(60×1000cosγ)；按 v_s 查表11-18（普通）或 11-19（ZC）得 f_v、φ_v（可插值）；η=(0.95~0.96)tanγ/tan(γ+φ_v)；用 η 重算 T₂ 复算接触/弯曲。热平衡 t₀=t_a+1000P(1−η)/(α_dS)≤80℃；不足加散热片/风扇，ΔP_F≈1.5v_F³/10⁵，P_f=(P−ΔP_F)(1−η)。
9. **结论表**：m、d₁、z₁、z₂、a、γ、材料与热处理、精度；注明“由齿面接触疲劳强度控制/弯曲校核通过”。

**与 ch10 的分界**：ch11 不用 Z_H/Z_E，接触式是 480 常数项；设计顺序是“接触设计 → 表11-1 选参 → 弯曲校核 → 热平衡”，不是齿轮的“试算 d₁ → 修正 → 取模数”两遍 K。K_FN 与 K_HN 的根指数/基准不同（9/10⁶ vs 8/10⁷），别混。

## 8. 易错点（按课本口径）

1. 式(11-9) 的分母是 **d₁·m²·z₂²**：d₁ 一次方，m 与 z₂ 平方；480 在根号外。
2. 式(11-10) 的 480/(z₂[σ_H]) **整个括号平方**，括号外只乘 KT₂。
3. 式(11-11) 的常数 **1.53** 已并入 b̃₂、m_n、Y_ε；分母是 **d₁d₂m**，不是 d₁m²。
4. K_HN 是 **8 次根号**、基准 10⁷；K_FN 是 **9 次根号**、基准 10⁶，两者不能混。
5. Y_β=1−γ/140° 的 γ 用**度**；z_v2=z₂/cos³γ 的 γ 用弧度。
6. 表11-7 的 268 MPa 对应 **10-1 锡青铜/金属模/蜗杆齿面 >45 HRC**；硬度 ≤45 HRC 或砂模铸造要换列。
7. 表11-9 分**单侧/双侧工作**；例11-1 单侧取 56 MPa。
8. 表11-18/19 的 φ_v 是度分字符串（如 `6°17'`），插值前先转十进制度；原表空格不得插值。
9. 表11-1 选参数时按 **z₁ 相同**的行筛 m²d₁，取 ≥ 设计值的最小标准值；例11-1 z₁=2 → m=8、d₁=80。
10. 蜗杆传动与齿轮不同：**先按接触强度设计 → 表11-1 选 m/d₁ → 弯曲校核 → 效率/热平衡**；不要套 ch10 的 Z_H/Z_E 体系。
