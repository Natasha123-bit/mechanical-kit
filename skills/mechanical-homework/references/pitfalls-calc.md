# 做题与取值的陷阱 · 计算/取值/单位/页码

> 自 `mechanical-homework/SKILL.md` 的「陷阱」一节按下沉，**正文逐字未改**；原节其余在另一份。条数以本文件的条目为准，不在标题里写死。

- **题干写「如图 X 所示」而图没发来，先要图，别用类型名称顶上**：旋向、正装/反装、压紧/放松、力的指向这类信息只存在于图里，类型名称（"角接触球轴承""正装"）只给一般定义。13-5 那次漏图仍算对是碰巧——按反装重算，F<sub>a2</sub> 由 1 435.2 变 3 175.2 N、P<sub>2</sub> 由 2 513 变 4 783 N，只因控制端是轴承 1，最终寿命才仍是 1 718 h。交付物里带错了中间值，比答案错更难解释。
- **公式库的角度量纲不统一，逐个函数定死**：`gear_ch10` 里 `eq10_19`（Y_β）**吃度**，而同章的 `eq10_23`（Z_β）、`轴向重合度`、`当量齿数`、`齿顶圆压力角_斜齿`、`eq10_17`/`eq10_20`（cos²β）**吃弧度**；`belt_ch08` 的 `eq8_31`（压轴力）吃弧度、`式8_6`/`式8_25`（包角）吃度。传错不报错、只出错，而且每道题错得一样：14° 当弧度传给 `eq10_23` 得 Z_β=1.357（应 1.015），d₁ₜ 被放大 1.9 倍，所有断言仍绿。传参前先过 `度()/弧度()`，并回读一个手算得出来的中间量（Z_β≈1.015、ε_β≈1.84）验量纲。
- **调用公式库前先 `inspect.signature` + 读 docstring，别按式号猜函数**：相邻式常是并列变体，套错不报错只出偏差——`eq5_29` 只含横向载荷，例5-1 那种横向+轴向组合要用 `接合面不滑移所需预紧力`（否则 F₀ 少算 700 N）；`eq8_31` 的 α 按库里规矩吃弧度，传度进去 F_p 偏高 1.7%。偏差落在 0.5%~2% 区间而断言仍绿，就是套错变体的典型症状。
- **同一章里量纲也会换轨，按式号认单位**：`key_ch06.eq6_1`（挤压强度）的 T 吃 **N·m**，而 `gear_ch10`/`shaft_ch15` 的设计式吃 **N·mm**，混用差 1000 倍（T=841.6 N·m 传成 N·mm 会算出 50 950 MPa）。把每个库里「T 的单位」写进调用处注释，或统一在入口乘/除一次。
- **查表函数的分类型参数必须抄表里的原文**：表8-8 的启动方式只认「空、轻载启动」「重载启动」，表14-1 的工作机只认 Ⅰ~Ⅵ 代号，表11-2 的螺栓要传 `'M14'` 字符串而不是 `14.13`，`轴承盖尺寸` 要传轴承外径、`平键选型` 要传轴径。自己编的描述词（「三相异步电动机」「带式输送机」「14.13」）一律 ValueError——这类报错要当好事，它比悄悄回落默认值安全得多。同类三处容易漏：①齿轮疲劳极限的**材料键是分图名不是钢号**——`查图10_21_sigmaHlim('调质钢', 280)`、`查图10_20_sigmaFlim('调质钢', 240)`，传 `'40Cr'` 直接 ValueError；②`查图10_19_KHN(N, 曲线=1)`、`查图10_18_KFN(N, 曲线=1)` **必须显式给曲线**（1 = 调质钢/允许一定点蚀，例10-1 走这条），不传不默认；③`表10_1_材料` 是 **dict**（键 `'40Cr调质'`/`'45调质'`，值 `[σ_B, σ_S, 硬度区间, …]`），不是可调函数，写成 `查表10_1_材料(...)` 会 AttributeError。
- **整章页图别靠 vision 磨**：原生通道虽快，但缩图上的小字会读错，公式主体没坏的页一律走 OCR 文本；真要读图就一次只问一件事（“抄本页编号公式”），批量读之前先报张数与用途让他决定。
- **引用的页码和表号都会漂**：模型（包括知识库的 chat）能把"表11-2 在 p.260"说成 p.259，也能把效率表写成「表2-4」（实为 **表1-5**，`std_data_ch01.传动效率`）、把精度选择写成「表10-6」（表10-6 是弹性系数 $Z_E$，`查表10_6_ZE`——精度等级压根没有对应表号，写「第10章正文/手册」）。凡是答案里要写页码或表号，先回源文件的 `## p.xxx` 标记核页码，**表号则从库的函数名反查**（函数名里的「表10_x」就是表号）；数值和公式形式很少错，错的多半是归因，而他会逐条核表号。
- **动手写模块前先扫一遍库里已有什么，待办/笔记里的「未做」是过期信息**：`search_files(pattern="^def ", path="lib/<book>")` 一趟就能看出图框/标题栏/明细栏/序号/模板这类东西早就验收过（记忆与桌面待办写「本批未做」但库里已在，照笔记重写一遍就是双份实现）。真的不存在再开工。
- **改一个尺寸要连带改一整圈**：用户临时把轴孔从 φ26 改成 φ50，`bore` 之外还有键槽 b/h/t₁/t₂（按 GB/T 1095 换区间）、毂槽深 d+t₂、端视图槽口断开角 `2·asin(KW/R_BORE)`、毂槽深 45° 引线斜率（一变就掉进剖面线判定窗，自检报“角度族 [45,133]”）、孔粗糙度引线落点（孔一大就压到齿顶圆），以及计算书那一节的措辞（估算值降格为“强度下界”）；改完三关重跑。细节见 `references/gb-gear-drawing.md`「直齿实心式齿轮」与 `references/calc-book-layout.md`「常见退回点」。
- **例题里的“从略/略”要补算**：教材为省版面常在最后一步写“改用 XX 轴承，验算从略”“强度校核略”；整题交付时那正是答案所在（改型号后的 P、L_h、静强度），照抄“从略”等于没给出最终件的寿命。先补完再排版，补算的数值同样进 `chNN.md` 的例题对比表。
- **复现书上数值时，中间量按书上写出的位数代入**：例13-1 的 F_a/C₀ 书上是 0.07105，插值才得 Y=1.597、P=8870.28、L_h=4509.12；用未截断的 0.0710526 得 Y=1.596，P 差 1.6 N、寿命差 2.5 h——算式没错，但和书值对不上就会被当成算错。断言直接写书值，别留「≈」。
- **参考图的结构形式不能照抄**：参考图 d_a>160 是腹板式，本题 d_a≤160 是实心式，照抄会让剖视图凭空长出轮缘和腹板；版式照抄、结构按判据。
- **同一数值有多处手写副本时，改一处等于没改**：键长/键规格（s0_params、s4、表9、表11、零件图 calc.json 至少五处）、轴段长度与总长（s3 → 表8/9 → 图2/3 → 零件图 JSON → 门禁）、技术要求条目数，都不是从单一真源算出来的。改完必须 `grep -rn "14×9×\|总长 \|技术要求"` 扫全仓再报完成——实测大齿轮键 56 是 b₂=60 时代的旧值，齿轮加宽到 72 后四处都没跟，用户一算「比轮毂短 16 mm」就抓出来。**这类值只在生成器里写一次、其余从 JSON 读**是唯一的根治办法。**零件图的 `calc.json` 尤其容易变旧**：它不参与说明书构建，也可能不进闸的判据——齿轮图那份里整块 `校核`（σH/σF/v/精度）停留在改材料之前的 512/545/108/302/1.13，键槽长还写着 56。交付前把它当一份普通产物逐个字段对 `s2.json` / `s4.json`，别只对键与段长；校核值不参与门禁，错了没人报错，但会被当成“图纸数据”。
- **σ_Flim/σ_Hlim 先看材料和硬度落在哪条线，再看数值**：图10-20c 上碳钢与合金钢调质是**两条曲线**，库按「≤250 走碳钢带、>250 走合金带」默认分流——**45 钢取 255 HBW 会被误判到合金带读成 478 MPa，碳钢线实为 326 MPa**（差 150，[σ_F] 高估 47%）。材料是碳钢就显式传 `'调质碳钢'`；超出该带印刷域（100~250）时按 ML 线 σ=0.4H+224 取并在正文写「沿曲线趋势取值」。图10-21c 只有 240(45钢)/280(40Cr) 两锚点连成的直线、域 240~280，硬度落在域外（如 225）**沿用最近锚点值 550 并说明「200~250 HBW 段接近水平」，不外推**。两处都别在说明书里出现「库/带/读数线」这类内部词，写成「图上碳钢与合金钢是两条曲线」。
- **改材料/硬度后必查「旁路产物」**：`calc/s0_params.py` 及其 JSON 不参与 PDF 构建，改了齿轮材料不会报错，却会留下一份旧参数（本次 280/240、φd=1.0 的 40Cr 数据在 s0 里躺了两版）。扫漏改的顺序是：s0 → s2 → s3 → s4 → 说明书各表 → 小结 → 参数确认单；口径以 `s2.json` 为准，逐个对表里的 σ_Hlim/σ_Flim/许用值/余量。旁路脚本里「圆整模数后接触不合格要上跳一档」这类规则也要实现，否则它算出的替代方案（如四极方案的 a=210）与说明书表里的对不上。
- **弯曲载荷系数 $K_F$ 不能沿用 $K_{H\beta}$，要按图10-13 另查 $K_{F\beta}$**：$K_{F\beta}$ 由 $K_{H\beta}$ 与 $b/h$ 两个量查得，$b/h=b_2/(2.25m)$（齿高 $h=2.25m$，别写成 2.25×1）。直接把 $K_{H\beta}$ 代进弯曲式会把 $\sigma_F$ 算高约 3.7%（实测 $K_{H\beta}$=1.340、$b/h$=10.667 → $K_{F\beta}$=1.292、$K_F$ 1.667→1.608，$\sigma_{F1}$ 72.4→69.8 MPa），而接触强度的 $K_{H\beta}$、$\sigma_H$ 与轴承选型**不受影响**——两套系数分开算、分开写。查图函数 `查图10_13_KFb(K_Hb, b_h)` 两个参数都必填；`s0` 与 `s2` 各有一处同样的写法，**两处都要改**，否则旁路 JSON 与说明书对不上。
- **功率链里的 $T$ 要写明是「名义转速」还是「实际转速」**：$T=9550P/n$ 换个 n 就差一个传动比误差（同一 2.640 kW，名义 60.02 r/min 给 420.0 N·m、实际 59.4 r/min 给 424.4 N·m，差 1.04%）。运动参数表整列统一一个口径（一般用实际转速），名义工况的转矩另在「工作机所需」一节给出；别把两个转速的转矩接成一条算式（写「442.08×0.96=420」而实际是 424.4，就是同一行里混了两套工况）。同理，V 带按电动机**额定**功率设计、轴与轴承的载荷按**所需**功率递推，两种口径并存时正文要有一句说明，并指出由此得到的 $F_p$ 与按所需功率算的差多少。
- **线速度按「该处」取，别拿齿轮分度圆速度顶整张表**：毡圈密封的适用速度看**密封处轴颈** $v=\pi dn/60$（φ35×297 r/min → 0.544 m/s；φ45×59.4 r/min → 0.140 m/s），不是齿轮分度圆速度 0.933 m/s。同一份说明书里 $dn$（轴承）、齿面速度（齿轮）、密封面速度（毡圈）各有各的对象，写润滑/密封那节时按位置逐个算——串用了不会报错，只是数字不对，而这类表用户会逐行核。
