# 阶梯轴零件图（GB/T）范式与出图前检查表

适用：输出轴/输入轴/阶梯轴的成品零件图（A3 横放 1:1 常见）。齿轮、蜗轮那套「全剖 + 参数表 + 端视图」不适用，见 `gb-gear-drawing.md`。

## 一句话口径

**轴零件图的价值在信息分层，不在标注密度。** 图面只放不可推的量（长度链、直径、形位公差框、基准、粗糙度符号）；「同一个公称直径在不同区段要求不同」和「重复出现的工艺要求」两件事搬出图面——前者进分区表，后者进技术要求条目。一根轴上几十个面靠区段 a/b/c 索引，而不是每段挂一个标注。

## 视图配置

- **主视图不剖**（轴类外形清楚，全剖会把轴肩、键槽、退刀槽全藏掉），轴线水平，两端倒角画成 45° 短斜线：两端点 `(x, ±(r−CH))` 与 `(x±CH, ±r)`，x 差 CH、y 也差 CH；写成同高度的两个点就是一条 1 mm 水平短线，端面与母线之间留 1 mm 缝，章程 L2-01 与 L1-03 同时报红。
- **端部倒角是四条线，不是三条**：① 母线在 `x_end∓CH` 停；② **倒角起点竖线**——圆柱面与倒角锥面的交线是 Ød 的圆，正投影就是一条**画满 ±r** 的粗实线，落在 `x_end∓CH`，两端与两条母线端点重合；③ 45° 斜线 `(x_end∓CH, ±r) → (x_end, ±(r−CH))`；④ 端面竖线只到 `±(r−CH)`。漏 ② 时母线末端与斜线之间是开口尖角，1:1 下 1 mm 斜线又被 0.5 线宽吃掉，整段看着像「母线断了、少一根可见轮廓线」——被用户截图指着退过两次。**套件已补判据 P-06**（mdkit `part/shaft.py`，2026-11-01）：两端各验端面 ±(r−c)、起点竖线 ±r、两条 45° 斜线端点对上，缺线直接红；`parts.倒角(端点线=True)` 是带这条线的原语。
- **CH 必须取自 calc 的 `派生.倒角`，不许在生成器里留常数**：模板里那句 `CH = rw(1.0)` 配「2×1.5×45°」的标注时，斜线只有 1 mm，0.5 线宽一压就只剩 6 px，母线—斜线—端面看起来「断了一截、少一条轮廓线」，用户看预览就会指出来。**P-06 会抓这条**（斜线端点必须正好落在 `(x_end∓c, ±r)` 与 `(x_end, ±(r−c))`，写死成别的值直接红）。自查仍可 PDF 渲成 PNG 后按 0.25 mm 步长打 ASCII 像素表，直接读母线终点是否在 `x_end∓c`、端面是否 `±(r−c)`、斜线增量是否等于 c。
  - **用户指着图说「少了一条线」时，先去量用户的参考图，别拿自己的图或套件样例自证**：把参考图放大 20~30 倍，按「母线 / 竖线 / 斜线 / 端面」逐条列它的线组，再列自己的，差哪条一目了然。**套件三张样例（`charter/fixtures/样例-输出轴`、中间轴）端部本身就只有三条线**——把它们当「已验收口径」必然得出「我画对了」的错结论；闸也没有这条判据（P-01 只按 C 给母线让步），51/51 全绿照样是废图。
- **轴肩圆角 R2 要画，不是直角**：母线在轴肩处**断开 RF**（1:2 时 R2 → 图面 1 mm），只有**细的那一侧**留 RF、粗的一侧直接贴轴肩（两侧都留 RF 会在接缝处留 1 mm 缝）。**控制点方向必须“起点切线沿母线（水平）、终点切线沿轴肩（竖直）”**——起点切线写竖直、终点写水平，就成一个向外凸的驼峰（犯过两次）。`φ80` 这类两侧都更粗的段，两端都贴轴肩。
  - **三次贝塞尔现在能过了，但仍要验**：`_flip_path` 已改为 `iter_path_commands`（M/L/H/V/C/S/Q/T/A/Z + 相对命令全认，参数个数不对则报错），`M 10 10 C …` 不会再被吞成折线。旧版只按 `[MLA]` 分段重拼、`C` 被当普通字符丢掉（输出 `M 10 90 10.5 90 11 89.5 11 89`），1:2 纸面加抗锯齿看着仍像圆的。**改完输出层一定要断言 `count('C')` 与源一致**；用 `A` 弧时半径给 0.02% 余量、坐标留 5 位小数（半径比弦距小一丁点，浏览器会静默把圆心移到弦中点，大弧塌成半圆）。详情见 `pitfalls-drawing.md` 同两条。
  - **圆角方向闸不能只数 `<path>` 个数**：方向反了、退化成折线，个数都还是 12。判据要落在几何上——弧起点的切线方向与母线平行、终点切线与轴肩平行，或直接取 `d` 的前四个点求斜率。
  - **弧的两个端点都必须是切点，不是尖角**：上台阶（小直径在左）`(x−R, r小) → (x, r小+R)`；下台阶（小直径在右）`(x+R, r小) → (x, r小+R)`。下台阶写成 `(x, r小) → (x+R, r小+R)` 时终点浮在轴肩面上方 1 mm，缩略图上是一个「翘起的钩子」，而半径、箭头、包围盒全合法。判据写成断言：一端在母线（`|y−MY| = r小` 且 `|x−x肩| = R`），另一端在轴肩面（`x = x肩` 且 `|y−MY| = r小+R`）。
  - **阶梯线（轴肩竖直粗实线）画满整个大直径，一截都不能少**：从 `−r大` 到 `+r大`，只在两侧圆角切点 `±(r小+R)` 处拆成三段（下段 / 中段 / 上段），三段端点分别与母线、圆角弧共用。中段看着「在实体内部」，其实是小直径过渡圆的投影——缺了这截轮廓就不闭合，用户一眼判「阶梯线又没画」。**为消 T 型接点把父线砍成两截短头是错解**：T 型接点要用「在切点处分段」消除，不是用「缩短父线」消除（砍短一版，必被退回重画）。断面缺口同理：槽壁止于 `x槽底+R根`、槽底止于 `±(b/2−R根)`，让两条 R0.3 弧与它们共用端点。
- **移出断面**（A—A、B—B）画在主视图下方，位置对应键槽所在轴段。断面 = 圆 + 一个矩形缺口：**缺口朝右**，槽底离圆心 d/2 − t₁，槽口落在圆周上；缺口内是空气，不画剖面线。
  - **轮廓发一条 `path`，不要用几百段折线拼圆**：`M 缺口上缘 A r r 0 1 0 缺口下缘 L 槽底 L 槽底 Z`。200 多段 0.4 mm 折线拼出来，“按角色找轮廓”的规则退化成数个数（L0 的 C8 会报「轮廓由碎线堆成」），SVG 体积也大一倍。
  - **但那条大弧要拆成两段 <180°**：`large-arc=1` 的圆心有歧义（弦长接近 2r 时两对标志里只有一对把圆心放在弦左侧），选错就把整圆镜像到弦外几十毫米，图上只剩缺口两侧各一截弧。稳妥写法：`M 缺口上缘 → A r r 0 0 0 (cx−r, cy)` + `(cx−r, cy) → A r r 0 0 0 缺口下缘`（最左点分界，两段都 `sweep=0`、`large=0`），自检按两段采样合并**最小二乘**拟合整圆、残差 ≤0.01（别用三点定圆：采样点近共线时会解出半径差 5 mm 的假圆，进而把正确的图判成错的）。半径别按比例留余量（`r*1.0002` 会把圆心推偏 0.04 mm、拟合就超差），只在弦长恰为 2r 的半圆端给 1e-4 绝对余量。
- **剖面线必须按材料域逐条裁切**：每条 45° 线单独求「圆内 且 不在缺口矩形内」的连续区间再画。`gbdraw.HATCH()` 只认凸多边形（扫描线取 min/max），喂带缺口的凹多边形会把斜线填进槽里；用白色矩形遮盖也走不通（`rect` 只认 class 描边，没有无描边白色样式）。DS-02 源码就是 34 条独立 `<line>`，端点全部精确落在圆弧/槽壁/槽底上。
- 自检写死一条断言：在缺口矩形内采样剖面线，命中数必须为 0。
- **主视图上必须有剖切位置符号**，断面标题「A—A」写在断面**上方**居中（GB/T 4458.6 的规定；写在下方是旧图的做法，会跟「槽底距」尺寸抢位置）。只有断面没有剖切符号 = 一对孤立的圆，这是最容易漏又一眼被看出的一条。
- 符号画法（DS-02 源码实测）：**轴的上下两侧各一组**，每组两条线——竖直粗短画（长 4、0.5 线宽，跨在轮廓线上）+ 从短画中点水平引出的细线（长 7）+ 箭头（2.5×0.9），字母写在短画/箭头一侧。全图 8 条 = 2 个断面 × 2 侧 × 2 条；只画一侧会被当成漏画。
- **第一角投影符号**（左下角）：截头圆锥**梯形 13×8**（四条细线）+ 右侧**同心圆 r=4 / r=2** + 十字中心线，下方 2 mm 处标「第一角投影」。DS-02 源码共 8 个元素。**要么不画，要么就是这 8 个**——用两个并排圆加一条横线代替属于瞎画。
- 退刀槽/越程槽/中心孔需要时说清画法：加局部放大图，比例单独标在放大图上方；不画就得在技术要求里交代（如「两端中心孔 B2.5 按 GB/T 145」）。
- **比例先算再定，别默认 1:2**：A3 横放内框可用宽 385（左 25、其余 10）。`总长 + 30 ≲ 385` 就取 **1:1**（295 mm 的轴 1:1 下图面饱满、字与键槽都不挤），394 mm 这种超框的才退 1:2；只有整数比（1:1、1:2、1:2.5），不取 1:1.5。

## 分区表（本范式最关键的结构）

**先问一句：这两处之间有没有台阶？** 同一根轴上公称直径相同、**中间没有台阶**的一整段连续圆柱面（如 φ45 从密封带一路到轴承颈、再到套筒位，90.5 mm 一根实体），只能给**一个**公差带——两个带等于在同一块材料上定两种加工要求、分两次对刀分两次检验，加工上不成立（用户原话口径：「不允许同一段实体材料上出现两种轴公差带」）。做法是整段取段内**最严**的那个：轴承颈 k6 覆盖密封段与套筒位，Ra 取 0.8，技术要求写「含密封带、不许螺旋纹」。代价只是磨削行程变长，**不新增工序**——密封面本来就要磨到 Ra1.6 且不许螺旋纹，同一次磨削走完即可，把密封段降成 h11 省不下工时。真要一紧一松，只能**加真台阶**（密封段降一级、端盖内孔与毡圈跟着改），那是结构改动，成本另算、交付前不做。

分区表只用于**被台阶隔开的两处独立表面**（同一公称直径，如两端 φ40 轴承颈各自成段，或图上 a/b/c 三段互不相连）：公称直径相同、要求不同，一根线挂不出三个公差，做成表：

| 区段 | 轴向范围 | 尺寸公差 | Ra |
|---|---|---|---|
| a | 0~18 | φ40 j6 | 0.8 |
| b | 140~158 | φ40 j6 | 0.8 |
| c | 171~180 | φ40 h11 | 0.4 |

- 表名写在表上方（「φ40 轴段局部要求」），表名下必须有一句「**轴向范围均自左端面起算（mm）**」——没有起算基准这张表没法用。
- 表下一行注明区段与基准的关系（「a、b 为基准 A、B 的轴承颈」），把表、基准、尺寸链三者扣起来。
- 位置：图右下方、技术要求上方、标题栏上方，右缘对齐内图框。
- 上了分区表以后，**只有进表那个公称直径**（如 φ40）在主视图上只标长度、不标直径公差，直径与 Ra 一律查表；其余轴段照常直标（DS-02 主视图上 φ45k6、φ52⁺⁰·¹、φ48₀⁻⁰·¹ 都是直标的，别一刀切）。

## 说明书的段表 ≠ 零件图的段表（同直径相邻段合并）

说明书轴段表里的「密封段 / 轴承段 / 套筒段」常常同为 φ45，实体上就是一根圆柱。零件图上只能标真实存在的台阶：把相邻同直径段合并成一段、标合计长度（54+19+17.5 → 90.5）。**合并之后这一整段只有一个公差带**——取最严的轴承颈 k6，Ra0.8，不许再用「分区表 + 轴向范围」把它切回 k6/h11：没有台阶却分带，就是同一段实体材料两种加工要求（写成 `138~157 k6 0.8`／`157~174.5 h11 3.2` 会被当场驳回）。这样既没有指向空气的尺寸界线，也没丢信息；交付时一句话说明哪几段被合并、合并后整段按哪个带走（用户会拿图跟说明书段表逐行对）。

- 合并后段名重排（Ⅰ~Ⅵ），生成器里一切按段名分支的地方都要跟着换：`SECT`/`SLOT` 的键、`i_seg = 1 if nm == "Ⅱ" else 3` 这种硬编码换成 `SEG_INDEX[nm]`，漏一处就是 KeyError 或把位置尺寸画到别的段上。

## 基准与形位公差

- 基准选**轴承颈（配合面）**，A、B 各自标在两端轴颈轮廓上（基准方框 + 三角贴在轮廓线上），不标在轴端面、不标在轴线上。
- **基准三角形方向按 GB/T 1182**：**底边**与基准要素轮廓线重合、**顶点朝外**（朝基准方框一侧），自顶点引出 2.4 连线到方框。尖端压在轮廓线上是 ISO 画法，在国标作业里算画反。判据写成断言：底边两点的 y 等于母线 y、第三点（顶点）比底边更远离零件。
- 跳动公差全部挂公共基准 **A—B**：轴承颈径向圆跳动 0.004（磨削面取小值）；键槽对称/轴肩端面跳动 0.02、0.012 同样写 A—B。
- 框格引线从框底边引出、箭头压在表面线上；不写「两端面」「轴颈」这类说明文字（GB/T 1182 只认框格）。
- 尺寸档（DS-02 源码实测，1:1）：公差框 **22×6**、首格符号格宽 **7**、格线 0.25；**圆跳动符号 = 小圆 φ2 + 自圆引出的一支 45° 斜箭头（杆 + 小 V 头）**——两条平行斜线在 GB/T 1182 里是「全跳动」，照抄会把跳动类型画错；从参考件 SVG 里量到「两条线」时先看它们是否交于同一点：交于箭尖 = 一支箭头（杆 + 一翼），平行不交 = 全跳动（参考件画错或本来就要全跳动），以标准为准并口头说明差异；基准符号 = 三角（底 3、高 2.6）+ 引线 2.4 + 方框 **6×6**；尺寸箭头三角 **2.5×0.9**（gbdraw 默认 3.0 偏大，要显式传 `size`）。
- 基准字母若同时用于分区表，字母（a/b/c 区段 vs A/B 基准）大小写分开，不能混用同一套符号。

## 键槽标法（断面里标宽与槽底距，主视图只标长与位置）

- 断面：方向由缺口朝向定。缺口朝右时，**槽宽 `14 N9` 竖直标在断面右侧**（尺寸线跨槽口上下壁，数字在尺寸线左侧），**槽底距 `39.5 ₀⁻⁰·²`（= d − t₁，t₁ 按 GB/T 1095 查孔径区间）水平标在断面下方**、从对侧母线量到槽底。槽宽竖直、槽底距水平——别两个都水平，也别照成「槽宽在上方」。
- 槽底距的**尺寸界线要从圆周引起**：左界线起点是圆的水平直径端点 `(cx−r, cy)`（与圆周相切），右界线从槽底线 `(cx+r−t₁)` 引下；从圆内偏下处起画会短掉半个圆，看着像没画完。
- 主视图：槽长 `63 ⁺⁰·³₀`、`70 ⁺⁰·³₀` 水平标在槽上方，槽端到端面 `6`；槽长公差只给上偏差、下偏差 0。
- 主视图键槽轮廓画**长圆（胶囊）**：两条水平粗实线（间距 = b、**居中于轴线**）+ 两端半圆，不画虚线。**到轴端的开口槽不画右端半圆**（两条边线直接落到端面线）——封了口就等于告诉加工“槽不到端”，是硬错。
- 技术要求补两条：两键槽在同一母线上、槽根 R0.25~0.40；键槽工作侧面 Ra1.6、槽底 Ra6.3。
- 键槽尺寸表：d≤30 → b=8/t₁=4.0；d=35 → b=10/t₁=5.0；44<d≤50 → b=14/t₁=5.5（配合面在用，逐个查 GB/T 1095，别沿用上一题）。

### 键长怎么定（剖面按轴径、长度按轮毂）

- **剖面 b×h 由轴径定死，不许「小一号省料」**：φ30→8×7、φ40→12×8、φ50→14×9。小一号属更小的轴径档（10×8 是 30~38 档），用在 φ40 上键槽要按非标宽度加工，而且工作长度变短、σp 反而更高（联轴器键 80→70：82.9→97.2 MPa，贴到许用 100）。大一号同理会加深键槽、削弱轴颈（φ50 用 16×10 要把 t 从 5.5 加到 6.0）。
- **长度 = 轮毂长 −(4~6)**，再取 GB/T 1096 标准值：48→40（各 4）、84→80（各 2）、72→63。**4~6 只是经验值**：它保证键槽两端不贴到轮毂/轴端的倒角，本身不承担强度；取值目标是「够长、不浪费」，凑经验值不构成改设计的理由。
- **标准序列在 63 与 70 之间没有值**：72 减 4~6 落在 66~68，取不到；取 70 只剩两端各 1 mm，键槽端部距轮毂端面太薄、装配与热处理易崩边，故取 63（两端各 4.5）。这种偏离 4~6 的取值必须在说明书正文写明理由（标准序列无 66~68），别把它写成常规取法。
- **轴伸短于轮毂时，键长按轴伸定、不按轮毂定**：联轴器 Y 型孔 112 配轴伸 100 时，键上限是 100−(4~6)=94~96（照「轮毂−4~6」会算出 106~108，比整根轴伸还长）——但**上限只是上限**：取 **80** 居中（两端各 10）就够，工作长 68、σp=82.9 MPa 满足许用 100，再长只是把轴上的键槽拉长、白削弱一段轴。**加长键只有一个正当理由：校核值逼近许用、要用更长的工作长度换余量**（大齿轮轮毂 72 配 56 时 σp=95.5 贴住 100，加到 63 降到 81.8）；「为了符合 4~6 这条经验值」不是理由。此时轴端已缩进孔内，技术要求里不许再写「轴端挡圈压紧」（装不上），改由台阶轴肩定位。
- 键长是**纯手写值**，同时出现在 s0_params、s4、表9/表11、零件图 calc.json 四处以上；改一处就 `grep -n "14×9×\|8×7×\|12×8×"` 扫全仓。

## 配合性质怎么判（间隙 / 过渡 / 过盈）

判据只有一条：把轴的最大/最小与孔的最大/最小逐一交叉——轴 max ≤ 孔 min → 全间隙；轴 min ≥ 孔 max → 全过盈；两者交叉 → 过渡。落成一句话给图/说明书：

| 配合 | 孔 | 轴 | 区间 | 性质 |
|---|---|---|---|---|
| φ30 H7/k6（带轮） | +21/0 | +15/+2 | 间隙 +19 ~ 过盈 15 | 过渡（偏紧） |
| φ40 H7/k6（联轴器） | +25/0 | +18/+2 | 间隙 +23 / 过盈 18 | 过渡（偏紧） |
| φ45 k6 — 6209 内圈 | 0/−12 | +18/+2 | 过盈 2~30 | 全过盈 |
| φ50 H7/r6（齿轮） | +25/0 | +50/+34 | 过盈 9~50 | 过盈 |

- **同一个 k6，配 H7 孔是过渡、配轴承内圈是全过盈**：轴承内圈孔公差是 0/−12（只往负方向出偏差），整条轴公差带落在它下方。所以轴颈只标 `φ45k6`、绝不写 `H7/k6`——对着轴承写 H7 没有对应的孔。
- 装拆口径顺手写清：过渡（k6+H7）轻压入、可拆；轴承颈压装、拆用拉马不敲内圈；r6 齿轮压装或热装 80~100 ℃。隔套（套筒）对 H11 是间隙，别和同一段上的轴承配合混为一谈。

- 图面只挂两处：视图内配合面少量（Ra1.6 / 0.8，箭头贴轮廓），和一处统一注法「▽Ra6.3 (√)」放右下方（标题栏上方）。**统一注法里不写「其余」二字**，符号形状见 `gb-gear-drawing.md`「表面结构符号」。

## 技术要求（轴类 8 条口径，每条都要能卡住加工）

1. 调质处理，硬度 217~255 HBW。
2. 未注线性、角度尺寸公差按 GB/T 1804—m；**未注几何公差按 GB/T 1184—K**（只写 1804 是漏项：图上既然挂了跳动框，就得交代未注的形位公差按什么）。
3. 未注圆角 R2、未注倒角 C1；台阶圆角 R1 点名是哪一处（参考件若写「上偏差 0、下偏差 −0.05」就照它的写法，别自造公差）。
4. 两键槽在同一母线上；槽根 R0.25~0.40。
5. 键槽工作侧面 Ra1.6，槽底 Ra6.3。
6. 各配合面（逐个写 φ 值）Ra1.6；定位端面 Ra3.2。
7. 密封接触带无螺旋加工纹；锐边去毛刺。
8. 分区表以外的未注轴径按 h11。

**不许用四条通用模板凑数**（未注圆角/倒角、材料、未注公差、中心孔）：模板里没有一条约束工艺，等于没写，用户一眼就判「这不是范式图」。

**8 条是口径，不是上限**：题目需要（轴端挡圈 + 螺纹孔、中心孔、动平衡、探伤…）就往下加。**新条目一律排在最后、编号顺延**——按「内容该放哪」插进去会得到「7、9、8」这种错序，用户会截图指明。改完把 `技术要求 N 条` 的计数一起改（docstring、自检记录、说明书正文引用处三处都有）。

## 版面与字符坑（A3 1:2、轴长 394 mm 实测）

- **符号字体缺字**：STFangsong 无 ↗（U+2197），公差框首格会渲染成斜线或空白 → 符号必须矢量画（斜线 + 小箭头，格宽 5.5、框高 5.9）。同类：`⁺⁰·³₀` 只能字符近似，要真上下标得改渲染层（`T()` 不支持 tspan）。
- **公差框、段长链、剖切符号分三层排**（从外到内：段长链/总长 → 公差框 → 剖切符号 → 轮廓）。DS-02 就全放在轴上方（框 y=63/79、剖切 88.5~92.5、轮廓 91）；1:2 的细长轴下方只剩 ~25 mm、三层塞不下时才把公差框挪到下方。判据是三层的 y 是否错开，不是「上方/下方」哪个固定。
  - **y 错开还不够，x 也要躲开段长界线**：段长链的界线从轮廓一路拉过链线，任何夹在「轮廓」与「链线」之间的公差框都会被它们穿过，L3-03 报「'A—B' 压线（净距 −0.12）」——那 0.12 就是界线正好压在基准格文字上。先把界线 x 列出来（= 各段界），只在塞得下 36 mm 三格框的空档里放框，引线竖直落到该空档里的目标表面；17.5 / 19 / 12 这类窄段没有空档，就把那几处的形位公差写进技术要求（「φ52 定位端面的端面圆跳动 0.02（基准 A—B）」），别为「每段一个框」把框挤进窄缝。
- **1:2 的轴下方只有 ~25 mm 可用**：公差框一整行 y≈178（框底）、键槽槽长尺寸 y≈168、键槽位置（5/10 这种小尺寸）y≈186 且箭头外置；剖切符号放**轴上方**（短画 + 水平箭头 + 字母，照 DS-02），否则与公差框抢位置。
- **小尺寸箭头必须外置**：5 mm 宽的位置尺寸，两个 3 mm 三角若都朝内会叠成一团；把尺寸线向两侧各延 5 mm、箭头从界线外侧指向界线。
  - **窄跨度的文字同样要外置**：4.5 / 5 这种两三毫米的跨距，居中文字的左缘正好压在尺寸界线上（L3-03 报「'4.5' 压线（净距 −0.12）」）。**调 `above` 只会把文字往尺寸线方向挪，越调越糟**；正解是这条尺寸的文字不走 `dim_h`（text 传空串），另用 `txt(界线x+1.5, row_y+1.2, "4.5", 3.5, anchor="start")` 画到界线外侧。
- **画布高度要装得下所有标签行**：件号/文字按 `cy + r_max + 9 + (j%2)×8.4` 交错排时，奇数行比偶数行低 8.4，`viewBox` 高度若按偶数行定，最外一条件号会贴着上边缘被切掉一半——闸不判这条，只有渲图才看得见。`H` 里把交错间距算进去。
- **机器自检只能证明排版规矩**（字体、线宽、箭头尺寸、界线越线、数字位置、文本包围盒重叠、越框），证明不了**画法对不对**：剖面线穿进键槽、开口键槽被半圆封死、剖切符号只画一侧，它一条都查不出，全绿也可能是废图。画法正确性只有两条路——对着参考件源码逐元素核，以及把几何判据写成采样断言（缺口矩形内剖面线采样数 = 0、开口槽两条边线是否落在端面线上）。**别把「8 项全绿」写成「已核」。**
- **参考件是 SVG 就先读源码**：带 `data-role`/`data-name` 的 SVG 等于一份可执行规格，能直接量出符号尺寸、剖面线端点、缺口朝向（做法见 SKILL.md 流程 5）。

## 定位轴肩要真能接触（交付前必查）

齿轮、联轴器靠轴肩定位时，单边高度 h 应 ≥0.07d，且**必须大于配合件孔口的倒角/圆角**——否则倒角把接触环带吃光，等于没定位。典型漏网：φ50 齿轮孔配 φ52 轴肩 → h=1 mm，孔口按「未注倒角 C1」加工后接触带为 0，图上那处圆角只能压到 R0.5、平段只剩 0.5 mm。这类说明书表里没人算过、图上却一眼看得出的事，**照说明书画、在交付说明里点出来并给最小改法**，不要擅自改已经交付的设计。

**轴肩直径两头都受夹，`da min` 只是下限、不是「越大越稳」**：

| 方向 | 约束 | 6209 + φ50 齿轮孔一例 |
|---|---|---|
| 下限 1 | 轴承安装尺寸 da min（表 6-1），小于它压不住内圈 | 52 |
| 下限 2（通常更紧） | 被定位件的孔口倒角（未注按 C1）+ 轴肩圆角 R0.5，单边须留够抵靠面 | 50 + 2×3 = **56** |
| **上限** | 轴承**内圈外径**（62/63 系列约 d+0.31(D−d)），越过去多出的那圈悬在保持架上方 | ≈57.5 |

所以这一例的正解是**单级 φ56×原长**：齿轮侧单边 3 mm（扣 C1 与 R0.5 后净 1.5 mm 够定位），轴承侧 56＜57.5 不碰内圈外缘。**不要拆成 φ58（顶齿轮）+ φ52（顶轴承）两级**——φ58 已越内圈外径，风险比 φ52 更大；而且表 6-1 只印下限，越界的那 1 mm 拿不出表值来辩护，答辩一问就哑。轴肩改直径**不动长度链**：17.5 还是 17.5，跨距、齿轮中心、弯矩、轴承寿命全部不变。

**改直径 ≠ 改总长**：报「总长 295→289」时先确认是**哪一段的段长**变了（本例是轴端 12→6，为把轴头缩进闷盖内腔），别把两件事写成一句「拆肩导致总长变」——用户会拿段长逐个相加反推，一句含糊就被抓住。

**轴肩圆角是第三个限值，方向和直径相反**：表 6-1 的 `r_as` 是该处轴肩圆角的**上限**（不是“推荐圆角值”），6207/6209 都是 **1.0**，而轴承自身倒角 `r_s` 是 1.1。圆角一旦 > `r_as`——按一般轴肩取 R1.5 或 R1.6 就会——内圈端面骑在圆角上、贴不实轴肩，轴向定位失效且装配顶死，而直径、段长、跨距全对，闸也不会红（它只核 `派生.圆角` 与图面一致）。所以：**轴承肩一律 R1（偏保守取 R0.8），只有非轴承台阶才用 R1.5/R2**；技术要求写成「轴肩过渡圆角一律 R1（≤ 该处轴承的 r_as）」并点名 φ56 这类非轴承定位肩另取 R0.5，别笼统写「轴肩圆角 R1.5、R1」——笼统写法等于告诉读图人和自己“轴承肩也可以是 1.5”。

同一张表的两列指向相反，别都当 max 读：`d_a` 只印**下限**（6207=42、6209=52，小于它压不住内圈），`r_as` 只印**上限**。说明书里写「轴肩 φ42 由 6207 的安装尺寸 $d_{a\max}=42$ 确定」是错的，42 是 $d_{a\min}$；正确表述是「取表 6-1 的 $d_{a\min}$=42（下限），圆角取 $r_{as\max}$=1.0（上限，小于轴承倒角 1.1）」。

18. 基准三角**底边**贴要素线、**顶点**朝外接方框（不是尖端压线）？
19. 两端倒角是**四条线**：母线停在 `±r` 且让出 CH、**倒角起点竖线画满 ±r**、45° 斜线从 `r` 落到 `r−CH`、端面只到 `±(r−CH)`；CH 取自 calc `派生.倒角`、与标注 `2×C×45°` 一致？（门禁 P-06 判这一组，跑 `--part shaft` 即可）
20. 公差框都落在段长界线之间的空档里（没有界线穿框）？窄段的形位公差是否改写成技术要求条目？
21. 键槽几乎占满整段的轴段，直径是否引到轴端外侧、尺寸线没有穿槽？
22. 断面名在图形**上方**？
23. 定位轴肩的单边凸台大于配合件孔口倒角（不会出现「倒角吃掉接触带」）？
24. 每个**轴承肩**的圆角 ≤ 该轴承表 6-1 的 `r_as`（6207/6209 均 1.0，小于倒角 1.1）？技术要求写的是「轴承肩 R1」而不是笼统的「R1.5、R1」？非轴承台阶才允许 1.5/2？

## 按 CSV 轴段表从零重画（顺序与踩点）

输入是「轴段 / 直径 / 长度 / 配合件 / 定位 / 键槽」那种表时，**先复制已过闸的同类生成器再改数据，别从零写**：
拿一份已过闸的同类生成器当模板（5 段轴、A3 1:1、门禁 51/51）连同它的 `calc.json` / `params.json`；本机没有就用 `mdkit/lib/drawing/charter/fixtures/` 里的中间轴 SVG + calc 当参照。只改五处：段表（段界/直径/段长/台阶 R）、键（b/t1/槽长/槽起止/槽底距）、`LAYOUT` 锚点、技术要求 8 条、标题栏文字；轮廓、圆角、断面、剖面线裁切、`features` 导出都不用动——这样一轮就能出图，重写一遍等于把已修过的坑再踩一次。
- **`键` 在 calc 的顶层，不在 `派生` 下**：模板自带的 calc 把 `键` 塞在 `派生` 里，`KEY = D["键"]` 换个按 `charter/calc.schema.md` 写的 calc 立刻 KeyError（`派生` 只有段界/半径/段长/台阶/圆角/倒角）。改成 `KEY = CALC["键"]`，并把 `_recon` 里那几条键长断言换成自己的槽长（模板里写死了 63.0）。
- **零件信息也别再读 `params.json`**：模板把名称/材料/比例/图幅放在 `params.json`，项目里通常只有 calc——把 `名称/材料/比例/图号` 与 `S/W/H/FR` 直接写成常量块，连带换掉 `PARAMS[...]` 的引用；不先改，KeyError 会一个接一个来。
真要重写时按这个顺序走：

1. **先派生再画**：CSV → `calc.json`（`段界`/`半径`/`段长`/`台阶`/`圆角`/`倒角`/`键`/精度分档）。键长按「**轮毂长 −(4~6) 取 GB/T 1096 标准值**」，b×h 由轴径按 GB/T 1095 对账。别用 `0.85×段长` 反推键长：84 的轴孔会得 70，白丢 10 mm 键长、σp 反而从 82.9 升到 97.2 贴住许用值。表里的键格常写成 `b\times h = 18\times 11` 这种 LaTeX 字面量，正则要认 `\\times`，只写 `[×x]` 会一个键都抓不到（表现为「键 {}」）。
2. **几何只从 calc 取**：图面坐标 = 版面锚点（`X0`、`MY`）+ 零件坐标 × 比例，1:1 时一一对应；生成器不另算段界/半径。
3. **用 `lib.drawing.sem.SemSheet` 打身份**，但**它不发 `id` 属性**：L3-06 的视图归属是按元素 id 关联浏览器 bbox 的，不覆写 `_emit` 补 `id`，`data-view` 写得再全也判「图上没有 data-view」。
4. **features.json 只声明真画出来的图元类型**：断面圆周是两段 `<path>` 弧，声明成「圆」立刻 L2-10 报「没有同心同径的圆」。
5. **段长链共用界线**：只给第一段画左侧界线，其余段左侧由上一段右界线兼任；每段各画一条，重合段会被 L2-08 判重复线（实测 4 条）。
6. **键槽长/位置的界线从轴线引**（L1-03 认轴线）；从槽边引，起点离轮廓 4.2 mm 直接红。
7. **竖排直径文字**要落在槽线与母线之间（`ty ≈ 轴线+18`，1:1 时），差 0.6 mm 就 L3-02 报「压 outline 净距 −0.25」。
8. **直径尺寸线别穿过键槽长圆**：x 偏移取段首 +4 mm（有键槽的段）/ +8 mm（无键槽）。**这条闸没判据，是目视整页才发现的**——出图后自己盯一眼有没有尺寸线穿轮廓。**槽几乎占满整段时（84 长的段配 80 长的槽）段内根本没有安全 x**：把该直径引到轴端外侧——两条水平界线从端面引出 7~8 mm、竖直尺寸线画在零件外、竖排文字落在线的外侧（左端文字在线的左边、右端在右边）；12 mm 的轴端短段同理引到端面外。
9. 出图 → `check.py 图.svg --part shaft --calc calc.json --fig-no …` → 绿了再出 PDF/PNG。

**定位压线到底压了谁**：别靠猜。`check_rules.make_ctx(svg, calc, fig_no, bounds, features)` 拿上下文，`capsules(ctx, {"outline", …})` 取胶囊，再对可疑文字框逐个 `box_cap_dist(box, cap)` 排序打印——证据行只给角色名，按 id 反查才知道是哪条母线。

实测：5 段 267.5 mm 的中间轴（A3 横放 1:1），CSV → PDF **4 分 15 秒**、门禁 51/51、3 轮迭代，迭代点就是上面第 5/6/7 条加断面清单。
