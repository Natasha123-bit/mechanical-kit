# 整机课程设计：带式输送机用二级圆柱齿轮减速器

单题计算书是「一道式算到底」，课程设计是「一张尺寸链从头串到尾」。本文件给流程与判据，**公式与表值仍按章读 `references/design/chNN.md`**，标准件查 `references/books.md` 指的手册。

## 一、交付形态

- 一题一目录（`~/Documents/Hermes/机械设计作业/<题目或测试名>/`），内含：`设计说明书.md`（源）+ `figs/`（SVG）+ `calc/`（分步计算脚本，每步 dump 一份 `*.json` 供后面步骤读）+ `build.py`（md→HTML→PDF）+ 成品 PDF。
- **章节顺序照题面列的顺序，别自拟**。常见 11 节：题目（含原始数据与传动方案图）→ 电动机 → 运动动力参数 → 传动零件（箱体内齿轮、箱体外带）→ 联轴器 → 轴（高速轴结构、低速轴结构与强度）→ 轴承 → 键 → 润滑密封 → 设计小结 → 参考文献。
- **交付前逐条数一遍题面要求**：要求「结构草图」就必须有图，要求「M 图、T 图」就必须有内力图，要求「1000 字以上」就用正则数中文字数（`len(re.findall(r'[\u4e00-\u9fff]', sec))`）而不是估。
- **自己先校一遍再交**：对危险截面从 $T$、$d$ 重推 $F_t\to R\to M\to W\to\sigma_{ca}$，**不复用脚本中间量**（脚本与图表同源于一支脚本时，错会一路自洽）；再量图——峰值比要等于弯矩比、峰点落在载荷截面、梁两端归零、T 图只覆盖传力段（见 `references/mech-frame.md`）。数值对不代表图对，图对不代表算法对，两道都要走。
- **改过参数/材料后必扫旧值**：`grep` 旧数（`302.6`、`15 HBW`、`HBS 240` 这类）过 `说明书_part*.md` 与 `calc/*.json`，并单独看**不参与 PDF 构建的旁路脚本**（`s0_params.py`、电机比选、参数确认单）——那里改了材料不会报错，能留两版旧数据。再逐项对三处：尺寸链各段求和＝总长、跨距按轴承中心重算、表↔图↔正文的同一数字要一字不差。
- **几何不变就别重画图纸，但要论证「不变」而不是声称**：功率链改动通常只传到 $T$、$\sigma$、寿命、$d_{\min}$，模数/齿数/中心距/齿宽/跨距/轴承型号很可能一位不动——判据是先在 `s2/s3` 的 JSON 里 diff 这些键，确认后再写「图纸不受影响」，别拿“大概没关”交差。

## 一·五、阶段闸：第一轮只出「参数确认单」，签字后才写正文

11 节的说明书**不要第一轮就整篇写**。他给完原始数据和目录后，第一轮只交「设计前参数确认单」，等一个字再动正文（原话：「先根据工作数据把正式开始设计前需要定下来的参数定好，待我看过以后再正式设计」）。抢跑写完 11 节，参数一改全篇返工。

落法：`<目录>/00_参数确定.md` + `calc/s0_params.py`（dump `s0_params.json`，后面 §1~§11 全从这份 json 取数），之后才是 `s1…s5`。

确认单按此顺序，每条带「依据」列（表几/式几）：①结论一览表 12~16 行（一眼能核）②原始数据 + 传动方案（为什么带放高速级、联轴器为什么选弹性柱销）③效率取值表 + η + P_d ④电动机比选 ⑤传动比分配 + 误差校核 ⑥各轴 P/n/T 表 ⑦寿命制度（班制、年工作日、L_h、轴承按大修期、N）⑧齿轮预选（齿型/材料/精度/φ_d/z/预估 m、a、b/σ_H 余量）⑨V 带预选（带型/直径/中心距/根数/压轴力 F_p）⑩联轴器、轴径与轴承初选、箱体、润滑、键 ⑪「待确认」≤5 项，每项写默认值 + 备选的代价。

**余量要报数字，别只报「通过」**：σ_H 只余 3.3% 时写明原因（m 圆整后 d₁ 只比需要的 58.9 大 1.8%）并给按**代价递增**的加严手段（φ_d↑ → z₁↑ → m↑），让他选而不是暗中加码。

## 二、计算链顺序（尺寸链闭合是主线）

1. **工作机**：$F=2T/D$、$n_w=60\times1000v/(\pi D)$、$P_w=Fv/1000$。数据给转矩+带速+卷筒直径时，先换成牵引力再往下走。
2. **总效率与电动机**：$\eta=\eta_{带}\eta_{齿轮}^2\eta_{轴承}^3\eta_{联}\eta_{卷}$（0.96、0.97²、0.99³、0.99、0.96 ≈ 0.833）；$P_d=P_w/\eta$ 后选手册表12-1（YE3/YX3/YE2），容量储备 1.2~1.3 即可。
3. **传动比**：先定带传动比（2~4，取 2.5 让大带轮不过大）→ 减速器 $i=i_总/i_0$ → 展开式取 $i_1\approx1.3i_2$；齿数取整后**回算实际 i 与 n_w，误差要 ≤±5%**。
4. **各轴 P/n/T**：按 **$P_d$ 链**逐级乘效率（不是额定功率），$T=9.549\times10^6P/n$（N·mm）。末级倒推要和题目给的转矩对得上，对不上就是效率链多算/少算了一环。
5. **两级齿轮**：接触强度设计（式10-24）→ 载荷系数修正（式10-12）→ 圆整 $m_n$ → 取整五/整十的中心距反算 $\beta$（要求 8°~20°）→ 接触/弯曲双校核。**螺旋角常落在 10°~12°**：$m_n$ 就近圆整后 $a$ 只能上下取，取到能满足 β 区间的那个。
6. **箱体外 V 带**：$K_A$→$P_{ca}$→带型与 $d_{d1}$→$d_{d2}=(1-\varepsilon)i d_{d1}$ 取标准→$L_{d0}$→**就近取标准带长**→$a$→包角→根数→$F_0$、$F_p$（$F_p$ 就是高速轴外伸端的径向载荷，要传给轴设计）。
7. **联轴器**（见判据）。
8. **轴**：$d_{\min}=A_0\sqrt[3]{P/n}$（45 钢 $A_0=103\sim126$，表注②减速器低速轴、单向旋转取**小值 103**）→ 结构直径序列 → **跨距**。
9. **轴承**：圆锥滚子成对正装，派生轴向力→压紧端→当量动载荷→寿命。
10. **键、润滑、箱体、附件**。

## 二·五、单位约定（本次真踩过的 1000 倍）

mdkit 里同一个符号 T 有三种单位，接错一次整份强度全错，且数字看起来「差不多」：

| 量 | 单位 | 怎么认 |
|---|---|---|
| P、n | kW、r/min | 题面直接给 |
| **T（运动参数表、`s1/s3` 的 JSON）** | **N·m** | 脚本写 `T = 9.549e6*P/n/1000`；数值量级 0.8~0.85（kN·m 写成 841.61） |
| **轴强度、弯矩、W/W_T** | **N·mm** | 用前 `T*1000`；量级 8.4e5，W=29 489 mm³、M=382 059 N·mm |
| **`key_ch06.eq6_1(T,d,l,h)` 键挤压** | **N·m** | 函数内按 4T/(dhl) 算，传 N·mm → σ 大 1000 倍（本次 50.9 MPa 变 50 900） |
| 齿轮公式的 β | **弧度** | mdkit 全库弧度，**唯 `eq10_19(ε_β, β)` 吃度** |
| 表值 b、h、D、轴承 T（装配高） | mm | 表4-1、表6-7；轴承装配高 T 和转矩 T 同名，别在同一个函数里混用 |

自检口诀：**功率链出 N·m，画图/强度先乘 1000，键校核退回 N·m**。写 JSON 时键名带上 `_Nm` / `_Nmm` 或注释标明。

## 二·六、单级（一级）减速器 + V 带：与二级不同的六处

题面常常是「带传动 + 一级圆柱齿轮 + 联轴器 + 卷筒」（简图 5 件），链条是二级版本做减法：

| 项 | 二级 | **单级** |
|---|---|---|
| 效率链 | $\eta_{带}\eta_{齿}^2\eta_{轴承}^3\eta_{联}\eta_{卷}$ ≈ 0.833 | **$\eta_{带}\eta_{齿}\eta_{轴承}^2\eta_{联}\eta_{卷}$ ≈ 0.867**——2 根轴 = 2 对轴承；卷筒 0.96 已含卷筒轴那一对，别再乘第 3 对（多乘一只 0.99 就少 1% 功率，回算 P 出 ≠ Fv 立刻露馅） |
| 分配 | $i_1\approx1.3i_2$ 展开式 | $i_{带}(2\sim4)\times i_{齿}(3\sim6)\le24$；齿比被顶到 6.0 说明该换 6 极电机 |
| 齿型 | 斜齿（β 8°~20°） | 直齿足够（单向平稳），无轴向力 → **深沟球轴承**，有粉尘工况轴承更好密封 |
| 轴承计算 | 圆锥滚子成对正装，算派生轴向力与压紧端 | 深沟球 $P=F_r$；寿命常由**带轮悬臂压轴力**控制 |
| 中心距 | 取整五/整十反算 β | $a=m(z_1+z_2)/2$ 直接得（180~210 常见）；m 只能取标准值 → σ_H 余量常只剩 3%~5% |
| 高速轴 | 齿轮轴 | 也做齿轮轴。单级常见死结：$e\ge2.5m$ 能取的齿轮孔是 φ30，而轴承颈为 6207 的 φ35（φ30＞不了 φ35，齿轮套不进去），缩到 6206 又寿命不够 → 一体。一体即同料，轴料一改小齿轮跟着改（见 §四 判据） |

**电动机选项不能只比 $i_总$**：把每个极数按实际传动比把带 + 齿轮各设计一遍再比。同一题实测：4 极 1440 r/min → $i_总$=24，逼成「带 4.0 + 齿 6.0」，z₂=120 使 **a=210、大齿轮 φ360**；6 极 960 r/min → $i_总$=16，落到「带 3.232 + 齿 5.0」，**a=180、大齿轮 φ300**。只比 $i$ 大小看不出这 30 mm 差距，而箱体是整个装置最贵的件，电机只大一机座。

**高速轴轴承按带轮压轴力核，不是按齿轮力核**：$F_p$（式8-31）作用在外伸端，$R_1\approx F_p(L+a)/L+F_r/2$ 与 $F_t/2$ 正交合成（实测 $F_p$=1299 N、L=115、a=100 → $R_1$=3383 N）。同一题 φ30 轴颈：6206（$C_r$=19.5 kN）算出 1.07 万 h，**低于大修期 1.44 万 h**；换 6207（25.5 kN）2.40 万 h。**外伸端轴径也常由结构而非扭转定**：扭转估算 23 mm，带轮段要 φ30（悬臂弯矩 130 N·m 落在轴承处那一截面）。

## 四、判据（别拍脑袋）

- **齿轮轴 vs 装配式**：$d_a<2d$ 或 $x=(d_f-d)/2<3.5m_n$ → 做成齿轮轴（手册表11-6 注）。高速级小齿轮几乎总是齿轮轴；低速级小齿轮与两个大齿轮常为实心/腹板式。**判据只是必要条件**：$e$ 过关后还要过装配路径——齿轮孔必须 ≥ 它要越过的每一段轴颈（密封段、轴承颈），否则根本无法套到轴中间；靠缩轴承颈来过这一关，先核寿命。两条任一不过就做齿轮轴，别在说明书里把"判据勉强"当理由，写"判据通过、装配路径不通"才站得住。
- **材料统一会改齿轮尺寸，能动的变量是有顺序的**：小齿轮与轴一体时轴料即齿轮料；许用 $\sigma_H$ 一降（40Cr→45 调质：549.7→521.1 MPa，$\sigma_{H\lim}$ 随硬度变），先动齿宽（$\phi_d$ 只能顶到**表 10-4 的上限 1.2**，再大 `查表10_4_KHb` 直接抛"超出表范围，不外推"），再不行才动模数（$m$ 一变 $a$ 就变，箱体、跨距、四张图全套重做）。另：**两张疲劳极限图的取数口径不同，别按同一个硬度硬套**——图10-20（弯曲）分碳钢/合金钢两带：45 钢走碳钢线 $\sigma=0.4H+224$（印刷域 100~250），**取 255 时若走库默认（>250 判合金带）会读成 478，那是 40Cr 的值，碳钢实为 326**，$[\sigma_F]$ 凭空高 47%；225 在域内正常给 314。图10-21（接触）只有 240(45 钢)/280(40Cr) 两锚点连成的直线、**域 240~280**，225 取不到——沿用 240 的锚点 550 并写明「图上该曲线 200~250 HBW 段接近水平」，不外推。所以同牌号两轮取 **255/225（差 30，正落在推荐 30~50）是可行的**，代价只是 $\sigma_{H\lim2}$ 一句注释，不是「只能 255/240 认命差 15」；而且 $[\sigma_H]$ 由小齿轮控制，大齿轮那个值只要 ≥464 MPa 就不改结论。
- **联轴器两道闸**：$T_{ca}=K_A T$（表14-1，带式输送机 Ⅰ 类、电动机 $K_A$=1.3）＋**轴孔直径**。`弹性柱销联轴器(Tn)` 的返回里有 `各档明细`，那才是完整轴孔表：**LX3（$T_n$=1250）有「30,32,35,38」与「40,42,45,48」两档**（Y 型 L=82/112、J 型 60/84），所以 φ40 的轴仍可用 LX3——按「LX3 只到 φ38」的印象跳 LX4，会把轴颈、端盖、箱体座孔一起放大一圈。顺序永远是：先 $T_n$ 定型号，再在 `各档明细` 里找 φd，都找不到才升一档。`按轴径选联轴器(d)` 返回的是**全部类型**，只能用来交叉看别家有没有更合适的，不能用它定弹性柱销的型号。
- **轴孔型别先定，轴伸长度、键长、悬臂三样跟着它走**：同型号有 J/J₁（短圆柱）与 Y（长圆柱）两种孔长，差很远（LX3 φ40：J=84、Y=112）。①**轴伸取 J 长度、与轮毂齐平** → 可用 GB/T 891 轴端挡圈压轮毂端面；②**轴伸取 Y 长度且短于孔长**（孔 112、轴伸 100）→ 轴端缩进孔内，挡圈无处安装，轴向只能靠台阶轴肩单向定位，说明书里不能再写「挡圈压紧」；③**悬臂不是「轴伸/2」**，而是「轴承中心到轴肩的距离 − 孔长/2」（100+54+9.5 − 112/2 = 119.5；按轴伸一半算是 113.5，差 6 mm）；④**键长上限变成「轴伸 −(4~6)」**而不是「轮毂 −(4~6)」（轴伸 100、孔 112 时上限 94~96，不是 106~108）——**上限不等于取值**：联轴器只传一道转矩，键取 **80** 居中（两端各 10）、工作长 68、σp=82.9 已满足，拉到 90 只为凑经验值，反而加长轴上的键槽；加长键只在强度逼近许用时才做（大齿轮 56→63，σp 95.5→81.8）。这四样要同一次改完：段表、键表、悬臂算式、零件图段界。
- **轴向力力偶**：$M_a=F_a d/2$ 在垂直面内，**同向、反向各算一遍取弯矩大者**，忽略它垂直面弯矩会少算近 40%。
- **压紧端 ≠ 危险端**：轴向力被顶到的那端 $F_a/F_r>e$ 取 $X=0.4,Y$，另一端 $F_a/F_r<e$ 取 $X=1,Y=0$；径向力大的端未必当量动载荷大，两头都要算再取 max。
- **轴承寿命由结构决定时如实写**：轴颈被联轴器轴孔（φ50）、密封段（φ55）逼到 φ60，02 系列最小就是 30212，$L_h$ 上百万小时是结构必然，不是算错。把它写成一句设计结论（「尺寸不由寿命控制，而由轴颈结构控制」），别为了数字好看去缩轴颈。
- **两张表各有一个 $K_A$，不是同一个数**：齿轮用表10-2（带式输送机＝「均匀平稳」+ 电动机 → **1.0**，1.25 是「轻微冲击」），带传动用表8-8（带式输送机 → **1.2**）。串了会让齿轮尺寸偏大 5% 或带轮偏小，两处都写清表号。
- **键的工作长度**：A 型键 $l=L-b$（扣两端半圆头），按 $l=L$ 算挤压应力会被低估 25%~30%。键长还得与轮毂长自洽：毂长 72 的齿轮配 56 的键仍可加到标准值 63（$\sigma_p$ 95.5→81.8），别在正文写「再长就超出轮毂」——数字自己会露馅。
- **压轴力的作用平面要写死，它决定轴承选型成不成立**：展开式（两轴水平、齿轮连心线水平）下 $F_r$ 沿连心线、$F_p$ 也沿连心线方向 → 两者同面，$F_t$ 在另一面；按「$F_r$、$F_p$ 同向相加」合成偏安全。**这一句必须进说明书**：同一组数换个假设，$R_1$ 从 3251 N 变 3886 N，6207 寿命从 20 351 h 掉到 11 900 h（＜大修期 14 400），选型直接翻盘。受力图里的「水平面/铅垂面」命名也要与布置对得上（$F_t$ 实际在铅垂面），否则图、文、方向三处打架。
- **轴承固定方式的术语不能混着写**：「双支点各单向固定（两端固定）」与「一端固定、一端游动」是两种方案；同一句里既写「双支点单向固定」又写「一端外圈轴向游动」＝自相矛盾，复核时第一个被问的就是它。
- **同一种材料在两张表里的 $\sigma_B$ 不同**：45 钢调质在表10-1 是 650 MPa、表15-1 是 640 MPa。全书只留一套口径，或在该处注明「本节按表15-1」；一份说明书里 650 与 640 并存，看上去就是抄错。

### 表19-1 版式（低速轴强度校核就用这个）

手册 p.255 表19-1 是**三栏**，不是两栏：

| 栏 | 宽度 | 内容 |
|---|---|---|
| 计算及说明 | 46%~52% | 每条按「公式 → 代入数值 → 结果」三行写，行首对齐 `=` |
| 结构简图与内力图 | 34% | **(a) 结构简图＋受力图**、**(b) 弯矩 $M_y$＋弯矩 $M_x$＋扭矩 $T$** 两幅竖窄图 |
| 结果 | 20%（约版面 1/5） | 只写该项最终值，一行一个 |

落法：md 里仍写三列 `| 计算及说明 | 结构简图与内力图 | 结果 |`，把 `@@FIG4A@@` / `@@FIG4B@@` 写进对应行的**中间单元格**，转档后用占位符替换把内联 SVG 塞进 `<td>`（替换是全文的，td 内同样命中）；再给这张表单独打 class 做固定列宽（`table-layout:fixed` + `th:nth-child(n)` 宽度），否则列宽由内容决定、图栏被压成一条。

落地细节（实测跑通的版本，照抄省一轮）：①class 与列宽靠 build.py 里的字符串替换——把唯一的 `<table>\n<tr><th>计算及说明</th>` 换成 `<table class="t19">` + `<colgroup><col style="width:52%"><col style="width:30%"><col style="width:18%"></colgroup>` + 原行；CSS 补 `table.t19{table-layout:fixed;font-size:8.6pt} table.t19 td svg{width:100%;height:auto;display:block} td{vertical-align:top}`。②中栏的图**不要**套 `.figwrap` 与自动图题，直接替换成裸 `<svg>`，图题（`（a）受力图（L=126，a=63，mm）`）写在占位符后面用 `<br>` 接一行 8.5pt 小字。③图的画布窄到 250 单位、字号 11~12，印在 55 mm 中栏里字高才 ≈2.4 mm；按 380 画会缩成 1.5 mm，看不清。④左栏禁止 LaTeX（见 `calc-book-layout.md` §七.6），一律 `× √ ² ³` + `<sub>`。⑤表跨页时表头不重复，行高控制在「一页两到三行」。

图幅与字号：中栏印出来约 55 mm，**画布宽 ≤380 单位、字号 ≥10.5 单位**才印得清；按 A4 版心宽（约 500 px）缩放渲染自检，别在 1180 px 上判断可读性。放不下就把计算过程多换行、图压小，不要改回两栏或让图另起一页。

行数多时表会跨页：`book.css` 默认 `.tbl{break-inside:avoid}` 会把整张表推到下一页、前页留半页空白，在注入的 `<style>` 里补 `.tbl{break-inside:auto}` + `.tbl table tr{break-inside:avoid}`；代价是跨页处表头不重复（要重复得给 md2html 加 `<thead>`）。

## 六、说明书与计算书的差别

计算书是「已知→解→（1）（2）」，说明书是「决策+依据」：每节先一句为什么这样选（带放高速级、斜齿而非直齿、展开式而非同轴式），再上公式。**设计小结 1000 字以上**要写取舍与反常结论（哪些级由接触强度控制、为什么寿命富余两个数量级、哪一处最紧），不要写流水账；把「每步都有据可查、同一个题能有多解」这一类收获放最后一段。

- **小结的「不足」只写设计本身的局限，不写交付进度**：直齿平稳性不如斜齿、同牌号硬度上限、没做考虑应力集中的疲劳校核、粉尘只做到毡圈+IP55——这些都行；「只出了主要零件草图与内力图，装配图尚未绘制」这类自述交付缺口不行，用户会要求删掉并连带清全文同类句子。交付版正文只说做完了什么，缺件写在交接/报告里，不在说明书里自曝；删的时候全文 `grep "装配图\|未绘制\|尚未"` 一遍，别只删小结那一处。
- **参数确认单要跟着改版回填，包括交付状态那一行**：`00_参数确定.md` 不进 PDF 构建链，改版后最容易停在旧值。数值（转矩、$\sigma_F$、寿命、Δ、键长、总长）靠 `grep` 旧数就能查；**「待确认/交付形式」那几行要按实际产物重写**——「若还要零件图/装配图，另开工时工作量翻倍」在两张零件图都交付以后就是假话，应改成「已完成 A、B 两张零件图，只差装配图」。收尾时把 §13 逐行对一遍实物，并把这次校对写成一个新版本头（v6 这类），别只在正文里悄悄改数。

## 八、报缺口的规矩

他做的是**套件测试**，会明确要求「不许给机械套件加功能」，并在交付后问「还缺什么」。此时：
- 先给出成品（PDF + 源 + 脚本 + 图），再单独列缺口，按「影响可信度 > 影响完整性 > 影响效率」排序；
- 每条缺口写「库里哪个函数/哪张表取不到 → 我用什么代替 → 这个替代值能不能被核」，**查图取的值要主动声明没逐格核**，别混在断言里冒充库值；
- 反面后果也写一句（例如：缺弯矩图作图能力 → 图全部手写 SVG、无法与计算脚本共用参数）。
