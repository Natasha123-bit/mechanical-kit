单题计算书是「一道式算到底」，课程设计是「一张尺寸链从头串到尾」。本文件给流程与判据，**公式与表值仍按章读 `references/design/chNN.md`**，标准件查 `references/books.md` 指的手册。

## 二、计算链顺序（尺寸链闭合是主线）

1. **工作机**：$F=2T/D$、$n_w=60\times1000v/(\pi D)$、$P_w=Fv/1000$。数据给转矩+带速+卷筒直径时，先换成牵引力再往下走。
2. **总效率与电动机**：$\eta=\eta_{带}\eta_{齿轮}^2\eta_{轴承}^3\eta_{联}\eta_{卷}$（0.96、0.97²、0.99³、0.99、0.96 ≈ 0.833）；$P_d=P_w/\eta$ 后选手册表12-1（YE3/YX3/YE2），容量储备 1.2~1.3 即可。
3. **传动比**：先定带传动比（2~4，取 2.5 让大带轮不过大）→ 减速器 $i=i_总/i_0$ → 展开式取 $i_1\approx1.3i_2$；齿数取整后**回算实际 i 与 n_w，误差要 ≤±5%**。
4. **各轴 P/n/T**：按 **$P_d$ 链**逐级乘效率（不是额定功率），$T=9.549\times10^6P/n$（N·mm）。末级倒推要和题目给的转矩对得上，对不上就是效率链多算/少算了一环。
5. **两级齿轮**：接触强度设计（式10-24）→ 载荷系数修正（式10-12）→ 圆整 $m_n$ → 取整五/整十的中心距反算 $\beta$（要求 8°~20°）→ 接触/弯曲双校核。**螺旋角常落在 10°~12°**：$m_n$ 就近圆整后 $a$ 只能上下取，取到能满足 β 区间的那个。
6. **箱体外 V 带**：$K_A$→$P_{ca}$→带型与 $d_{d1}$→$d_{d2}=(1-\varepsilon)i d_{d1}$ 取标准→$L_{d0}$→**就近取标准带长**→$a$→包角→根数→$F_0$、$F_p$（$F_p$ 就是高速轴外伸端的径向载荷，要传给轴设计）。
7. **联轴器**（见判据）。
8. **轴**：$d_{\min}=A_0\sqrt[3]{P/n}$（45 钢 $A_0=103\sim126$，表注②减速器低速轴、单向旋转取**小值 103**）→ 结构直径序列 → **跨距**。
9. **轴承**：圆锥滚子成对正装，派生轴向力→压紧端→当量动载荷→寿命。
10. **键、润滑、箱体、附件**。

## 二·五、单位约定（本次真踩过的 1000 倍）

mdkit 里同一个符号 T 有三种单位，接错一次整份强度全错，且数字看起来「差不多」：

| 量 | 单位 | 怎么认 |
|---|---|---|
| P、n | kW、r/min | 题面直接给 |
| **T（运动参数表、`s1/s3` 的 JSON）** | **N·m** | 脚本写 `T = 9.549e6*P/n/1000`；数值量级 0.8~0.85（kN·m 写成 841.61） |
| **轴强度、弯矩、W/W_T** | **N·mm** | 用前 `T*1000`；量级 8.4e5，W=29 489 mm³、M=382 059 N·mm |
| **`key_ch06.eq6_1(T,d,l,h)` 键挤压** | **N·m** | 函数内按 4T/(dhl) 算，传 N·mm → σ 大 1000 倍（本次 50.9 MPa 变 50 900） |
| 齿轮公式的 β | **弧度** | mdkit 全库弧度，**唯 `eq10_19(ε_β, β)` 吃度** |
| 表值 b、h、D、轴承 T（装配高） | mm | 表4-1、表6-7；轴承装配高 T 和转矩 T 同名，别在同一个函数里混用 |

自检口诀：**功率链出 N·m，画图/强度先乘 1000，键校核退回 N·m**。写 JSON 时键名带上 `_Nm` / `_Nmm` 或注释标明。

## 四、判据（别拍脑袋）

- **齿轮轴 vs 装配式**：$d_a<2d$ 或 $x=(d_f-d)/2<3.5m_n$ → 做成齿轮轴（手册表11-6 注）。高速级小齿轮几乎总是齿轮轴；低速级小齿轮与两个大齿轮常为实心/腹板式。
- **联轴器两道闸**：$T_{ca}=K_A T$（表14-1，带式输送机 Ⅰ 类、电动机 $K_A$=1.3）＋**轴孔直径**。库的 `弹性柱销联轴器(Tn)` 只按转矩给型号，转矩够但轴孔装不下时必须改大一档（LX3 孔 30~38、LX4 孔 40~56），并用 `按轴径选联轴器(d)` 交叉核；说明书里把「按转矩该选 X，按轴孔改选 Y」写出来。
- **轴向力力偶**：$M_a=F_a d/2$ 在垂直面内，**同向、反向各算一遍取弯矩大者**，忽略它垂直面弯矩会少算近 40%。
- **压紧端 ≠ 危险端**：轴向力被顶到的那端 $F_a/F_r>e$ 取 $X=0.4,Y$，另一端 $F_a/F_r<e$ 取 $X=1,Y=0$；径向力大的端未必当量动载荷大，两头都要算再取 max。
- **轴承寿命由结构决定时如实写**：轴颈被联轴器轴孔（φ50）、密封段（φ55）逼到 φ60，02 系列最小就是 30212，$L_h$ 上百万小时是结构必然，不是算错。把它写成一句设计结论（「尺寸不由寿命控制，而由轴颈结构控制」），别为了数字好看去缩轴颈。
- **键的工作长度**：A 型键 $l=L-b$（扣两端半圆头），按 $l=L$ 算挤压应力会被低估 25%~30%。

### 表19-1 版式（低速轴强度校核就用这个）

手册 p.255 表19-1 是**三栏**，不是两栏：

| 栏 | 宽度 | 内容 |
|---|---|---|
| 计算及说明 | 46%~52% | 每条按「公式 → 代入数值 → 结果」三行写，行首对齐 `=` |
| 结构简图与内力图 | 34% | **(a) 结构简图＋受力图**、**(b) 弯矩 $M_y$＋弯矩 $M_x$＋扭矩 $T$** 两幅竖窄图 |
| 结果 | 20%（约版面 1/5） | 只写该项最终值，一行一个 |

落法：md 里仍写三列 `| 计算及说明 | 结构简图与内力图 | 结果 |`，把 `@@FIG4A@@` / `@@FIG4B@@` 写进对应行的**中间单元格**，转档后用占位符替换把内联 SVG 塞进 `<td>`（替换是全文的，td 内同样命中）；再给这张表单独打 class 做固定列宽（`table-layout:fixed` + `th:nth-child(n)` 宽度），否则列宽由内容决定、图栏被压成一条。

图幅与字号：中栏印出来约 55 mm，**画布宽 ≤380 单位、字号 ≥10.5 单位**才印得清；按 A4 版心宽（约 500 px）缩放渲染自检，别在 1180 px 上判断可读性。放不下就把计算过程多换行、图压小，不要改回两栏或让图另起一页。

行数多时表会跨页：`book.css` 默认 `.tbl{break-inside:avoid}` 会把整张表推到下一页、前页留半页空白，在注入的 `<style>` 里补 `.tbl{break-inside:auto}` + `.tbl table tr{break-inside:avoid}`；代价是跨页处表头不重复（要重复得给 md2html 加 `<thead>`）。

## 六、说明书与计算书的差别

计算书是「已知→解→（1）（2）」，说明书是「决策+依据」：每节先一句为什么这样选（带放高速级、斜齿而非直齿、展开式而非同轴式），再上公式。**设计小结 1000 字以上**要写取舍与反常结论（哪些级由接触强度控制、为什么寿命富余两个数量级、哪一处最紧），不要写流水账；把「每步都有据可查、同一个题能有多解」这一类收获放最后一段。

## 八、报缺口的规矩

他做的是**套件测试**，会明确要求「不许给机械套件加功能」，并在交付后问「还缺什么」。此时：
- 先给出成品（PDF + 源 + 脚本 + 图），再单独列缺口，按「影响可信度 > 影响完整性 > 影响效率」排序；
- 每条缺口写「库里哪个函数/哪张表取不到 → 我用什么代替 → 这个替代值能不能被核」，**查图取的值要主动声明没逐格核**，别混在断言里冒充库值；
- 反面后果也写一句（例如：缺弯矩图作图能力 → 图全部手写 SVG、无法与计算脚本共用参数）。
