## 一、箱体：中心距 a 进去，整套结构尺寸出来

**问：a=150、1 级圆柱齿轮减速器，箱座/箱盖壁厚、凸缘、地脚螺栓、各连接螺栓是多少？**

`箱体结构尺寸(150, "齿轮", 1)` →（表11-1，p.164）

| 量 | 值 | 规则 |
|---|---|---|
| δ 箱座壁厚 | 8 | 0.025a+1≥8 |
| δ₁ 箱盖壁厚 | 8 | 0.02a+1≥8 |
| b 箱座凸缘 | 12 | 1.5δ |
| b₁ 箱盖凸缘 | 12 | 1.5δ₁ |
| b₂ 箱座底凸缘 | 20 | 2.5δ |
| df 地脚螺钉 | 17.4（计算值） | 0.036a+12 |
| n 地脚螺钉数 | 4 | a≤250 |
| d₁ 轴承旁连接螺栓 | 13.05（计算值） | 0.75df |
| d₂ 盖座连接螺栓 | 8.7~10.44 | (0.5~0.6)df |
| d₃ 轴承端盖螺钉 | 6.96~8.7 | (0.4~0.5)df |
| d₄ 视孔盖螺钉 | 5.22~6.96 | (0.3~0.4)df |
| 定位销 d | 7~8（按 d₂=M10） | (0.7~0.8)d₂ |
| l 连接螺栓间距 | 150~200 | 表11-1 |
| Δ₁ 大齿轮顶圆与内壁 | >9.6 | >1.2δ |
| Δ₂ 齿轮端面与内壁 | >8 | >δ |
| m₁/m 肋厚 | 6.8/6.8 | 0.85δ₁ / 0.85δ |

**关键限制（零猜测）**：表11-1 只给系数和“≥”下限，**不给标准螺栓直径取整规则**。df=17.4 不能自动写成 M18；d₂=8.7~10.44 也不能自动写成 M10。要选标准螺纹必须查第3章（本批未做）。所以 L2 返回计算值/范围，图上取标准值由设计者定。

给了标准螺栓公称才回填扳手空间：`箱体结构尺寸(150, 螺栓公称="M12")` → C₁=18、C₂=16、R₁=16、l₁=39~44（表11-2，p.167）。

**问：地脚螺钉数目怎么定？**
- 齿轮：a≤250→4；a>250~500→6；a>500→8。
- 蜗杆：4。
- 锥齿轮：n=底凸缘周长之半/(200~300)≥4；未给周长不给数。

**问：凸台/凸缘的 C₁、C₂、D₀、R₀max、rmax？**
`凸台凸缘尺寸("M10")` → C₁min=16、C₂min=14、D₀=22、R₀max=5、rmax=5（表11-2；M6~M30，超范围报错）。

**问：轴承旁凸台半径、凸台高度、外壁至轴承座端面距离？**
R₁=C₂；凸台高度按低速级轴承座外径确定、以扳手操作为准（表11-1 只给这句，不给公式）；l₁=C₁+C₂+(5~10)。

**问：轴承端盖外径？**
D₂=D+(5~5.5)d₃，D 是轴承外径（表11-1）。`轴承盖外径(62,6)` → 92~95。

## 二、视孔盖 / 通气器 / 轴承盖 / 套杯

- **视孔盖**（表11-4，p.167）：`视孔盖尺寸(150,1)` → l₁=90、l₂=75、b₁=70、b₂=55、d=7、孔数=4、盖厚δ=4、R=5。单级 a≤500、双级 aΣ≤650；超范围报错。
- **通气器**（表11-5，p.168）：一个表号下三组子表。
  - `通气器尺寸("通气塞","M12×1.25")` → D=18、D₁=16.5、s=14、L=19、l=10、a=2、d₁=4。
  - 通气帽 M27×1.5 → 孔数 6；通气罩 M18×1.5 → d₁=M33×1.5。
  - 表中还有“提手式通气器”结构图（固定 φ25/φ10/φ4），无独立参数子表。
- **凸缘式轴承盖**（表11-10，p.172）：`轴承盖尺寸(62)` → d₃=6、螺钉数 4、d₀=7、D₀=77、D₂=92、D₄=46~50、D₅=59、D₆=58~60、e=7.2、b=5~10、h=4~10。b₁、d₁ 由密封件尺寸定，m 由结构定。
  - 轴承外径 D 与 d₃/螺钉数：45~65→6/4；70~100→8/4；110~140→10/6；150~230→12~16/6。
- **嵌入式轴承盖**（表11-11，p.172）：s₁=15~20、s₂=10~15、e₂=8~12、e₃=5~8、b₂=8~10、D₃=D+e₂；b、h 见表7-13（本批未核）。结构②标注 D₃(H9)/D(h6)。
- **套杯**（表11-12，p.172）：s₃=s₄=e₄=7~12、D₀=D+2S₃+2.5d₃、D₂=D₀+2.5d₃；D₁ 由轴承安装尺寸定。

## 三、齿轮/蜗杆/蜗轮结构（表11-6~11-9）

这些表是“结构形式 + 尺寸关系”，不是数值表：

- 圆柱齿轮（表11-6，p.169）：实心式 δ₀≥3、d₁=1.6d、d₀≈d_a/20≥15、D₀=0.5(D₁+d₁)；腹板式 δ₀=2.5mₙ≥8~10、d₀=0.25(D₁-d₁)、C=C₁=0.3B、r=5；铸造 H=0.8d、C=0.25H≥10、C₁=0.8C、s=0.17H≥10、e=0.15~0.2d、R=0.4H。
  - 注：x<3.5m 或 d_a<2d 时做成齿轮轴。
- 锥齿轮（表11-7，p.170）：齿轮轴 x≤1.6m；实心式 d_a≤200；腹板式 d_a≤500。d₁=1.6d、l=(1~1.2)d、δ₀=(3~4)m≥10、C=(0.1~0.17)R≥10。
- 蜗杆（表11-8，p.170）：车制 d₁-d≥2~4；铣制 d 可大于 d₁。L≥2m√(z₂+1)（不变位）或 L≥√(d_a2²+d₂²)（变位）。
- 蜗轮（表11-9，p.171）：d₃=(1.6~1.8)d、l=(1.2~1.8)d、d₄=(1.2~1.5)m≥6、l₁=3d₄、a=b=2m≥10、C=1.5m≥10、R₁=0.5(d₁+2.4m)、R₂=0.5(d₁-2m)、d_a2=d₂+2m、f≥1.7m、R=4~5；D_w、B 上限按 z₁ 分档；d₅ H7/s6（或 H7/r6）、d₆ H7/r6。
