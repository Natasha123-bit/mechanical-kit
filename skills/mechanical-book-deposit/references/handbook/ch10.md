## 画图时会问 → 答案 → 出处

### 1. 精度 7 级、模数 2.5、d=60 的齿轮，检验项目表填什么？

```python
from gear_tol_ch10 import 齿轮检验项目
齿轮检验项目(7, 60, 2.5, b=20)
# fpt=12, Fp=38, Fα=16, Fβ=15,
# f_fα=12, f_Hα=10, f_fβ=11, f_Hβ=11,
# F''i=43, f''i=13, Fr=30  （单位 μm）
```

- 表10-6（p.135–137）分三块：单个齿距 fpt/齿距累积 Fp/齿廓总偏差 Fα（d,m 分档）、
  齿廓形状 f_fα/齿廓倾斜 f_Hα（d,m）、螺旋线 Fβ/f_fβ/f_Hβ（d,b）。
- 表10-7（p.138）径向综合 F''i/f''i 与径向跳动 Fr（d,m_n）。
- 档内不插值；b 未给时 Fβ 类不返回。

### 2. 公法线长度与跨齿数

```python
公法线长度(24, 2.5)   # k=3, W'=7.7165, Wk=19.2912 mm
公法线长度(40, 2)     # k=5, Wk=27.6896
公法线长度(100, 3)    # k=12, Wk=106.0503
```

- 表10-11（p.141）是 m=1、α=20° 的 W' 表；`Wk = W' × m`。
- 斜齿/变位齿轮要用表10-10 的公式，本函数暂不覆盖（抛 NotImplementedError）。

### 3. 最小侧隙与中心距偏差


- 表10-8 只给 a=50/100/200/400/800/1600 固定列；中心距不在列上抛 ValueError，不插值。
