## 2. 编写注意（常见扣分点）

```python
from manual_ch19 import 说明书编写注意
说明书编写注意()   # 三点（p.254）：
```

1. 用打印件；手写用蓝、黑色钢笔或圆珠笔，**不得用铅笔或彩色笔**；书写工整、简图
   正确清楚、文字简练。
2. 计算内容**列出公式→代入数值→写下结果→标明单位**，**中间运算省略**。
3. 编大小标题，附必需插图（如轴的受力分析图）和表格，写**简短结论**（如"满足强度
   要求"），**注明重要公式或数据的来源（参考文献编号和页次）**。

- 纸张与装订：16 开纸书写，加封面（图19-1 格式：机械设计课程设计/计算说明书/
  设计题目/系（院）/班/设计者/指导教师/年月日/校名）后装订成册（p.254）。

## 3. 书写格式长什么样？（表19-1）

```python
from manual_ch19 import 书写格式行
书写格式行()   # 11 行：左「计算及说明」右「结果」
# 示例段：七、轴的设计及核验计算 → 1. 低速轴的计算 → 结构和受力如图××所示 →
# （1）轴上作用载荷 → …… →（2）计算轴承支反力 → 1）铅垂面内支反力 →
# F_By=(79×10^-3·F+55×10^-3·F_1-M_a)/(110×10^-3) → =(79×10^-3×760+55×10^-3×665-10.95)/(110×10^-3) → =779 N
# 右栏全书仅一个值：F_By=779 N（与「1）铅垂面内支反力」行就近归行）
```

- 表19-1（p.255）：这是**格式示例**不是数值表——层级文字「七、→1.→（1）（2）→1）」
  + 分式两行 +「=779 N」，照抄不改写。
- **「铅垂面/弯矩M_y/水平面/弯矩M_x/扭矩T」及 F=760 N、F_Ay=874 N、M_Ay=60 N·m、
  M_Cy左/右=42.83/53.78 N·m、F_Ax=F_Bx=892 N、M_Cx=49.06 N·m、T=49.52 N·m 等是
  图××（轴结构图 a + 受力/弯矩/扭矩图 b）的内部标注**，不是左栏文字行（F 回页图
  放大裁决，与委托预期不符处已存证于注）。

## 4. 答辩前准备（p.254–255）

- 答辩是检查设计能力、评定成绩的重要方式；答辩前**认真整理和检查全部图纸和计算
  说明书**，系统全面回顾，弄懂计算、结构等问题。
- 图纸按**图19-2 格式折叠**（210×297，A4 图纸对折再折，主标题栏折在外），
  图纸与计算书装入文件袋，文件袋封面按**图19-3 格式**（机械设计课程设计/设计题目/
  内装 1.2.3.…/系（院）班级/设计者/指导教师/完成日期/成绩/校名）。
- 图19-1~19-3 为格式图，无数量值可查 → `封面或折叠格式()` 抛 `NotImplementedError`。
