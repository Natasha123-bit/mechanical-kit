### 1. 动力机（电机/液压/气动/内燃机）怎么比较？


### 2. 传动机构怎么选？单级传动比给多少？

```python
from system_ch14 import 传动机构性能, 单级传动比范围
传动机构性能("齿轮传动", "许用线速度（一般精度等级）", 齿式="圆柱")   # '≤15~30*'
单级传动比范围("齿轮传动", "常用值", 齿式="圆柱")   # 原文 '圆柱 3~5' → 3.0~5.0
单级传动比范围("齿轮传动", "最大值", 齿式="锥")     # 5.0（全章 OCR 漏了这个 5，回页图核出）
单级传动比范围("蜗杆传动", "常用值")               # 10.0~40.0
```

- 表14-2（p.200）：平带/V带/圆柱摩擦轮/链/齿轮/蜗杆 六机构 × 15 项指标。
- **齿轮传动必须给 齿式（'圆柱'/'锥'）**：传动比、许用线速度两行书上一格分左右子格，
  不消歧会混口径；其余行两子格为合并大格同值。
- 功率行印「功率/kW（常用值）」（OCR 误作 /W）；带 * 两格 = 脚注「上限为斜（曲）齿轮，
  下限为直齿轮圆周速度」。
- **传动效率行只给「见表 1-5」指针**，效率数值在 ch01 `std_data_ch01.py` 表1-5；
  正文口径：一般取中间值，工作条件差、润滑维护不良取低值（p.199–200）。
- 行星减速器效率随形式/传动比/主动件选择差异极大（0.98 以上到接近 0 甚至自锁负值），
  书上不给统一值（p.200）。

### 5. 传动布置顺序（多级传动怎么排，正文判据 p.204）

带传动→高速级（平稳缓冲吸振）；链传动→低速级（速度不均有冲击）；
蜗杆传动→高速级（紧凑、易形成油膜）；斜齿轮→高速级或平稳场合；
锥齿轮→高速级并限制传动比（大模数难加工）；开式齿轮→低速级（易磨损寿命短）。

### 6. 公式（p.199–200，全书仅有的 14-1~14-5）

- 式14-1 P_d = P_w/η（P_w 工作机需输入功率 kW，η 电动机至工作机总效率）；
- 式14-2/14-3 P_w = F·v/1000η_w = T·n_w/9550η_w；
- 式14-4 η = η_0·η_1·η_2·…·η_n（每传动副/轴承对/联轴器效率连乘，概略值查 ch01 表1-5）；
- 式14-5 n_d = i′·n_w = (i′_1·i′_2·…·i′_n)·n_w（各 i′_n 为各级合理传动比范围，
  查 ch01 表1-6 或本章表14-2）。
- 电机转速倾向：YE3/YX3 常选同步 1500/1000 r/min，无特殊需要不用 <750 r/min（p.200–201）。
- 电动机具体选型（型号/功率/转速/安装尺寸）在 ch12 `motor_ch12.py`。

**5 式已落成函数**（批6·B，`system_ch14.py` 末段，docstring 含式号/原式/符号单位/出处页）：
`设计功率(P_w, η)`（式14-1）、`工作机功率_力(F, v, η_w=1.0)`（式14-2）、
`工作机功率_扭矩(T, n_w, η_w=1.0)`（式14-3）、`总效率(η列表)`（式14-4，结果 round 4 位）、
`电动机转速范围(i范围列表, n_w)`（式14-5，传 `[(下,上),…]` 返回 `(下限, 上限)`）。
用法一行：`设计功率(3.2, 0.86) → 3.7209`；`电动机转速范围([(3,5),(3,5)], 100) → (900.0, 2500.0)`。
单位按手册口径（kW/N、m/s、N·m、r/min）不自动换算；非法参数（η≤0、v<0、n_w≤0、
空列表等）一律 `ValueError`，不静默返回 0。
