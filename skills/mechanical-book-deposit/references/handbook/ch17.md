## 一、装配图上到底标哪些尺寸？

**问：装配图上要标四类尺寸，具体是哪四类、每类举什么例子？**

`装配图尺寸类别()`（p.243，七.1）：

| 类别 | 书上例子 |
|---|---|
| 特性尺寸 | 传动零件中心距及其偏差（参见表10-15） |
| 最大外形尺寸 | 减速器总长、宽、高 |
| 安装尺寸 | 箱体底面尺寸、底座凸缘厚度、地脚螺钉孔中心线的定位尺寸及其直径和间距、减速器中心高、轴伸端的配合长度与直径 |
| 主要零件的配合尺寸 | 轴与箱内外传动件、轴承、联轴器的配合；轴承与轴承座孔的配合；**同时注出配合与精度等级** |

## 二、配合代号怎么给？

`装配图配合("一般齿轮")` → H7/r6，用压力机（中等压力的配合）（表17-2，p.243）。

| 配合零件 | 荐用配合 | 装拆方法 |
|---|---|---|
| 大、中型减速器的低速级齿轮（蜗轮）与轴、轮缘与轮芯 | H7/r6、H7/s6 | 压力机或温差法（中等压力，小过盈） |
| 一般齿轮、蜗轮、带轮、联轴器与轴 | H7/r6 | 压力机（中等压力） |
| 要求对中性良好、很少装拆的齿轮/蜗轮/联轴器与轴 | H7/n6 | 压力机（较紧的过渡配合） |
| 小锥齿轮及较常装拆的齿轮/联轴器与轴 | H7/m6、H7/k6 | 手锤打入（过渡配合） |
| 滚动轴承内圈与轴 | 查表6-10 | 压力机（实际为过盈配合） |
| 滚动轴承外圈与箱体孔 | 查表6-11 | 木锤或徒手装拆 |
| 轴承套杯与箱座孔 | H7/h6 | 木锤或徒手装拆 |

**注意**：书里明写「这些配合不要求全注，仅供设计时参考」。偏差值去第9章查（`tolerance_ch09.配合偏差`）。

## 三、密封方式怎么选？

`密封方式选用(轴表面速度, 工作温度)` → 适用/不适用/温度待判（表17-1，p.231）。

| 密封方式 | 适用圆周速度 (m/s) | 适用工作温度 |
|---|---|---|
| 毡圈密封 | <3~5 | <90 ℃ |
| 橡胶油封 | <8 | <-40~100 ℃（书上原样写法） |
| 迷宫密封 | <5 | 低于润滑脂溶化温度（定性） |
| 径向迷宫密封 | <30 | **原表空白** |

「<3~5」是书上原样范围，取值由设计者定；本库按上限比较，并把定性/空白的温度项放进「温度待判」，不硬判。

## 四、技术要求写什么？

`技术要求条目()` 返回六组（p.244–245，七.3）：

1. **润滑剂**：品种、用量、更换时间；一般半年换油，第一次 2~3 个月。
2. **轴承轴向游隙及调整**：可调间隙查表6-16；固定间隙向心球轴承留 Δ=0.25~0.4 mm。垫片调整法：先顶紧 → 端盖与箱体间有 δ → 放 δ+Δ 的一组垫片。
3. **传动侧隙与接触斑点**：侧隙与中心距有关，接触斑点按精度定，数值查第10章；侧隙用塞尺/铅丝测，斑点用涂色法。
4. **密封**：剖分面、接触面、密封处不许漏油；剖分面允许涂密封胶或水玻璃，**不许塞任何垫片或填料**。
5. **试验**：空载正反转各 1 h；负载试验油池 ≤95 ℃、轴承温升 ≤40 ℃。
6. **外观包装运输**：箱体涂漆；外伸轴涂油包装，运输不可倒置。

## 五、零件编号与明细表

`零件编号规则()`（p.245）：编号完全、不重复；相同零件一个号；标准件可混标；引线不交叉、尽量不与剖面线平行；独立组件（轴承、通气器）可算一个件；螺栓组可用公共引线；按顺/逆时针排列；**编号数字比尺寸数字大一号**。

`明细表要求()`（p.245）：每个编号都要有；材料注牌号；标准件写全名称/材料/规格/标准代号；箱内传动件注 m、z、β、λ；格式见第一章表1-12。

## 六、装配底图阶段的几条尺寸规则（都有印刷式/不等式）

| 问 | 答案 | 出处 |
|---|---|---|
| 箱体内壁与齿轮端面/齿顶圆留多少？ | Δ≥δ，Δ₁≥1.2δ（δ 为箱座壁厚） | p.217 |
| 两级齿轮端面间距？ | >2m，且 ≤8 mm | p.217 |
| 箱体底部内壁到最大齿轮顶圆？ | b₀>8m，且 ≥30 mm | p.218 |
| 箱座壁厚经验式？ | δ=2·⁴√(0.1T) ≥8 mm（T 为低速轴转矩 N·m） | p.233 |
| 箱体轴承孔处轴向尺寸？ | L≥δ+C₁+C₂+(5~10) mm，C₁/C₂ 查表11-2 | p.222 |

**都不给取整规则**：δ 算出 5.32 就返回 5.32 与下限 8，不替你圆整；L 的 5~10 返回区间。
