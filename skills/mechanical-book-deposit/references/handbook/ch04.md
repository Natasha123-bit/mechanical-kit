## 画图时会问 → 答案 → 出处

### 1. 轴径 d、轮毂宽 B 定了，平键怎么选？

```python
from key_ch04 import 平键选型
平键选型(35, 键长=50, 配合="正常")
# b=10, h=8, t=5, t1=3.3, r=0.25~0.40,
# 轴槽 N9: 0/-0.036, 毂槽 JS9: ±0.018,
# 轴槽组合 30-0.2, 毂槽组合 38.3+0.2/0,
# 键标记 "键 10×8×50 GB/T 1096"
```

- b×h、t、t1、r 全部按表4-1（p.56）的 d 档取；**档内不插值**。
- d 的档位是 `自 6~8`、`>8~10`、…、`>95~110`；d=8 属于第一档（b=2），d=8.5 才进第二档。
- d>110 抛 `ValueError`，不外推。
- **键长 L 表4-1 只给系列，不给“L 与轮毂宽 B”的数值关系**；第17章 p.220 只有“键应较配合长度稍短”的定性要求。所以 `键长=None` 时库返回 `None`，由设计者定；给了 L 只校验它在系列内。

### 2. 键槽在工作图上怎么标？

| 标注对象 | 图上写法 | 库函数 |
|---|---|---|
| 轴槽深 | `(d−t)`，偏差取 t 偏差的负号 → `30-0.2`（30 的 0/−0.2） | `键槽标注_轴(35, 5.0, "+0.2/0")` |
| 毂槽深 | `(d+t1)`，偏差同 t1 → `38.3+0.2/0` | `键槽标注_毂(35, 3.3, "+0.2/0")` |
| 键的标记 | `键 10×8×50 GB/T 1096`；B 型 `键 B 14×9×63 GB/T 1096` | `平键标记(10, 8, 50)` |
| 键宽配合 | 毂/轴 → `8JS9/N9`、`14D10/H9`、`28P9/P9` | `键宽配合标注(8, "正常")` |

- 表4-1 注1：轴槽深用 `t` 或 `(d−t)` 标注，轮毂槽深用 `(d+t1)` 标注。
- 表4-1 注2：`(d−t)`、`(d+t1)` 的极限偏差按相应 t/t1 选取，`(d−t)` 取负号。
- 表4-1 注3：键宽 b 为 h8、键高 h 为 h11、键长 L 为 h14。
- C 型（单圆头）标记需要 `_anno.键槽标注` 增接口；当前库抛 `NotImplementedError`，不手拼。

### 3. 三种配合的偏差（按键宽 b）

| 配合 | 轴槽 | 毂槽 | b=8 的偏差 |
|---|---|---|---|
| 松连接 | H9 | D10 | +0.036/0、+0.098/+0.040 |
| 正常连接 | N9 | JS9 | 0/−0.036、±0.018 |
| 紧密连接 | P9 | P9 | −0.018/−0.061（轴毂同值） |

```python
平键配合偏差(8, "松")   # 轴H9/毂D10
键槽深度与半径(8)        # t=4.0, t1=3.3, +0.2/0, r=0.16~0.25
```

- b 的偏差列在表4-1 是**纵向合并**的，五组：b=2~3、4~6、8~10、12~18、20~28；查询走合并回落。
- t/t1 偏差只有两档：b=2~6 → +0.1/0；b=8~28 → +0.2/0。
- r 四档：b=2~4 → 0.08/0.16；5~8 → 0.16/0.25；10~18 → 0.25/0.40；20~28 → 0.40/0.60。

### 4. 导向平键（表4-2，p.57）

```python
导向平键选型(40, L=100)
# b=12, h=8, h1=3, 螺钉 M4×10, 沉孔 D=8.5, L0=10,
# L 范围 28~140, L1=60, L2=50, L3=20
```

- 表4-2 的列头是键宽的 11 个规格（8,10,12,14,16,18,20,22,25,28,32），不是轴径；轴径 d 只用来按表4-1 反查 b×h（表4-2 注2）。
- b<8 时表4-2 无规格，抛 `ValueError`。
- L 必须落在该 b 的 L 范围内、且在 L 系列上。

### 5. 矩形花键（表4-3，p.58）

```python
矩形花键选型(32, 系列="中", 装配形式="固定", 精度="一般")
# 8×32×38×6, C=0.4, r=0.3, d1min=29.4, amin=1.0,
# 内 H7/H10/H9·H11, 外 h7/a11/h10
```

- 小径 d 只有 16 档：18,21,23,26,28,32,36,42,46,52,56,62,72,82,92,102。
- **轻系列没有 d=18、21**（书上该两行轻系列为空）。
- 公差带：一般用 3 行（f7/g7/h7），精密传动用 6 行（f5/g5/h5/f6/g6/h6）；按装配形式（滑动/紧滑动/固定）选行。
- 精密块内同一装配形式有 H5/H6 两行，用 `内d公差带=` 消歧；未给时取前一行。
- 表4-3 注1：精密传动内花键需控制键侧间隙时槽宽取 H7，一般取 H9；注2：d 为 H6/H7 的内花键允许与提高一级的外花键配合。
