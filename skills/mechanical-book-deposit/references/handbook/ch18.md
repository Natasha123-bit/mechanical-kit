## 一、零件图要有哪些内容？

图形、尺寸及其公差、表面粗糙度、几何公差、材料与热处理及其他技术要求、标题栏（p.248）。
视图：每个零件单独一张标准图幅，尽量 1:1；**轴类（含齿轮轴、蜗杆轴）一般一个视图**，键槽/孔加剖面，螺纹退刀槽/砂轮越程槽/齿形画局部视图；**齿轮类一或两个视图**；组合式蜗轮要另画齿圈、轮体的零件图与组件图。

## 二、尺寸基准怎么选？

`尺寸基准("轴")` / `尺寸基准("齿轮")` / `尺寸基准("锥齿轮")`（p.248–250）。

| 零件 | 规则 |
|---|---|
| 轴 | 先定基面 1（图18-1）；L₂、L₃、L₄、L₅、L₇ 都从基面 1 注；**最不重要的一段作封闭环不注**，避免封闭尺寸链；同一尺寸的几段轴径逐段标注，不得省略 |
| 齿轮/蜗轮 | 径向以**孔中心线**为基准，齿宽以**端面**为基准；**分度圆必须标**；**齿根圆不标**（由参数加工得到）；中心孔要标偏差；齿顶圆偏差取决于它是否作测量基准 |
| 锥齿轮 | 锥距精确到 0.01 mm；锥角精确到分；分度圆锥角精确到秒；还要注基准端面到锥顶的距离 |
| 蜗轮组件 | 注齿圈与轮体的配合尺寸、精度及配合性质 |

## 三、轴各表面的 Ra 取多少？

| 与 G、E 级滚动轴承相配合的表面 | 见表6-14 |
| 与传动件及联轴器相配合的轴肩端面 | 6.3，3.2 或 3.2，1.6 |
| 与滚动轴承相配合的轴肩端面 | 见表6-14 |
| 平键键槽 | 工作面 6.3，3.2 或 3.2，1.6；非工作面 12.5，6.3 |

## 五、轮坯要标哪些位置公差？

`轮坯几何公差("齿顶圆的径向圆跳动")`（表18-4，p.252）：

- 圆柱齿轮以顶圆作测量基准时，齿顶圆的径向圆跳动；
- 锥齿轮齿顶圆锥的径向圆跳动；蜗轮外圆、蜗杆外圆的径向圆跳动；
  （以上四项共用精度的「按齿轮、蜗轮精度等级确定」）
- 基准端面对轴线的端面圆跳动；
- 键槽侧面对孔中心线的对称度（7~9）。

影响：齿顶圆跳动影响齿厚测量精度与齿圈径向跳动；锥齿轮/蜗轮/蜗杆那组会造成加工中心与使用中心不一致、分齿不均、齿向误差；基准端面跳动会让齿轮倾斜或心轴弯曲。

## 六、技术要求怎么写？

`技术要求条目("轴", "45 钢", "调质处理后硬度 220~250HBW", "R1.5", "C1.5", "m")` →
1. 材料 45 钢，调质处理后硬度 220~250HBW；
2. 未注圆角半径为 R1.5；
3. 未注倒角为 C1.5；
4. 未注尺寸公差按 GB/T 1804-m。

书的六类（p.252）：材料力学性能与化学成分；铸件毛坯（不许氧化皮/毛刺）；热处理与表面硬度、硬化层/渗碳层深度；配钻配铰；未注圆角倒角与局部修饰；平衡试验、长轴校直、涂漆电镀等。
图20-8/20-9 还示范了箱体类专用的：时效处理、合箱错位 ≤2、0.05 塞尺与涂色接触斑点、打定位销后镗孔、禁放衬垫、组合后加工、铸造圆角 R3~R5、未注倒角 C2 及 Rz/ Ra 值、不得漏油。
