```python

# d=50, D=90, B=20, rs=1.1, da=57, Da=83, ras=1,
# Cr=35 kN, C0r=23.2 kN, 脂 6700 / 油 8500 r/min
轴承安装尺寸("6210")   # da=57, Da=83, ras=1, rs=1.1
```

- 表6-1 深沟球（6000/6200/6300/6400）、表6-2 圆柱滚子（N/NF，02/03/04/22）、
  表6-3 调心球（12/13/22/23）、表6-4 调心滚子（22/23）、表6-5 滚针（49/69）、
  表6-6 角接触球（C/AC，10/02/03）、表6-7 圆锥滚子（02/03/22/23）、表6-8 推力球（12/13/14/22/23/24）。
- 表6-2 的 N/NF 两套额定载荷分开取；NF 型号按『代号 NF』列识别。

### 2. 轴上、箱体孔各标什么公差带？

| 场景 | 表 | 函数 | 典型结果 |
|---|---|---|---|
| 向心轴承·轴 | 表6-10 | `轴公差带(轴承类型, 载荷状态, 运转状态, d)` | 深沟球/正常/旋转内圈/d=50 → `k5②` |
| 向心轴承·孔 | 表6-11 | `孔公差带(轴承类型, 载荷状态, 运转状态, 结构)` | 球/轻/固定外圈 → `H7、G7②` |
| 推力轴承·轴/孔 | 表6-12 | `推力轴承公差带(轴承类型, 部位)` | 轴 `j6,js6`；孔球 `H8`、孔滚子 `H7` |

- 表6-10 三种轴承类型列的内径档不同（深沟球/调心球/角接触球、圆柱/圆锥滚子、调心滚子）。
- 表6-10 注1：精度要求高时用 j5、k5 代替 j6、k6；注2：圆锥滚子/角接触球可用 k6、m6 代替 k5、m5；
  注3：重载荷下游隙应大于 N 组。
- 表6-11 注1：并列公差带随尺寸增大从左至右选；注2：不适用于剖分式轴承座。
- 表6-11 的 `H7、G7②` 是并列写法，图上取哪一个要按尺寸与精度定；库原样返回并列串，不替设计者二选一。

### 3. 几何公差取多少？

```python
几何公差(50, "P0", "轴颈")      # 圆柱度 4 μm
几何公差(50, "P6", "轴肩")      # 轴向圆跳动 8 μm
几何公差(200, "P0", "轴承座孔肩")  # 轴向圆跳动 30 μm
几何公差框格("轴颈", 0.005)      # ["⌭","0.005"]
```

- 表6-13：圆柱度 t（轴颈/轴承座孔）、轴向圆跳动 t1（轴肩/轴承座孔肩），
  公差等级 `/P0` 与 `/P6(/P6x)` 各一列；表值是 μm。
- 注：/P0 = 旧 G 级，/P6 = E 级，/P6x = Ex 级。

### 4. 配合面 Ra 取多少？

```python
配合面粗糙度(55, "IT6", "磨")        # 0.8 μm
配合面粗糙度(100, "IT7", "磨")       # 1.6 μm
配合面粗糙度(50, "IT7", "车", "端面") # 6.3 μm
粗糙度标注(0.8)                      # "Ra0.8"
```

表6-14：直径 ≤80 / 80~500 两档，IT7/IT6/IT5 各分磨/车；端面单列一行。
注：与 /P0、/P6 级轴承配合的轴一般 IT6，座孔一般 IT7。

### 5. 轴向游隙多少？

```python
轴向游隙("角接触球", 50, 接触角=15, 结构="I")   # 30~50 μm，允许间距 7d
轴向游隙("角接触球", 50, 接触角=25)             # 15~30 μm
轴向游隙("圆锥滚子", 100, 接触角=10, 结构="II") # 120~200 μm，间距 10d
轴向游隙("推力球", 100, 型式="51200")           # 40~60 μm
```

表6-16 是参考值：上块角接触球/圆锥滚子（I/II 型、允许间距以 d 的倍数给），
下块推力球（51100/51200及51300/51400）。单位 μm。
