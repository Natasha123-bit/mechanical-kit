### 1. 轴上零件的轴向固定，挡圈选哪种、尺寸哪里查？

```python
from fastener_ch05 import 轴肩挡圈, 锁紧挡圈, 轴端挡圈, 孔用弹性挡圈, 轴用弹性挡圈, 交付串
轴肩挡圈(40)          # D₁≥42 + 三组尺寸系列（(0)2/(0)3/(0)4）各自的 D/H（表5-1，GB/T 886）
锁紧挡圈(30)          # d/D 共用 + 锥销锁紧(883) H/d₁/C/圆锥销 + 螺钉锁紧(884) H/d₀/C/螺钉
轴端挡圈(55)          # 共用 H/L/d/d₁/C + 螺钉紧固(891) 与 螺栓紧固(892) 分别取列 + 安装尺寸(参考)
孔用弹性挡圈(10)      # 孔用弹性挡圈(A型)：d₃/s/b≈/d₅min + 沟槽 d₂(±偏差)/m/t/n + 轴 d₄≤
轴用弹性挡圈(40)      # 轴用弹性挡圈(A型)：同构列，配合列名为「孔 d₄≥」
```

- **表5-1~5-5 全在「一、挡圈」小节**（p62~65）：轴肩挡圈（表5-1）、锥销/螺钉锁紧挡圈
  （表5-2）、轴端挡圈（表5-3）、孔用弹性挡圈（表5-4）、轴用弹性挡圈（表5-5）。
- **锁紧挡圈一表两标准不拆**：d、D 两列共用，GB/T 883（锥销）与 GB/T 884（螺钉）各占
  4 列；配套件圆锥销 GB/T 117、螺钉 GB/T 71 的规格串直接在列值里（如 `6×50`、`M8×12`）。
- **轴端挡圈（表5-3）双标准共表分别取列**：GB/T 891（螺钉紧固）与 GB/T 892（螺栓紧固）
  并排共列 D/H/L/d/d₁/C，L2 按标准分组返回；注3 明确「轴端单孔挡圈的固定」图不属于
  这两个标准，仅供参考，未并入标准正文。
- **孔用/轴用弹性挡圈分块不合并**：孔用在表5-4（GB/T 893—2017，d₁ 自 8 起）、轴用在
  表5-5（GB/T 894—2017，d₁ 自 3 起），规格系列起点不同、配合列名相反（「轴 d₄≤」对
  「孔 d₄≥」）。查不到直接 ValueError，不许跨表猜。

### 2. 圆螺母与止动垫圈怎么配套？

```python
from fastener_ch05 import 圆螺母, 止动垫圈, 圆螺母配套止动垫圈
圆螺母('M16×1.5')            # 812/810 两栏各一行（d_K=30/d₁=22 对 d_K=28/d₁=None）
圆螺母('M25×1.5')            # 带 * 规格：仅 812 一行，仅滚动轴承锁紧装置
止动垫圈('M55×2')            # 规格 55*：d 照书 56，轴端 t 书「—」存 None
圆螺母配套止动垫圈('M16×1.5')  # 两表按螺纹大径一次取齐
```

- **配套关系**：表5-6 圆螺母（GB/T 812—1988）、小圆螺母（GB/T 810—1988）与表5-7
  圆螺母用止动垫圈（GB/T 858—1988）配套使用；表5-7 行标签「规格（螺纹大径）」与表5-6
  的 D×P 一一对应（10~105），L2 按螺纹大径建立关联。
- **`*` 号含义**：仅用于滚动轴承锁紧装置，标记必须保留。表5-6 的 * 规格仅出现在
  GB/T 812 圆螺母栏（M25×1.5*、M35×1.5*、M40×1.5*、M50×1.5*、M55×2*、M65×2*、M75×2*），
  小圆螺母栏无对应行；表5-7 的 * 规格为 25/35/40/50/55/65/75。
- 表5-6 同一规格在两栏各出现一次属**左右两块并排各成一栏**，非同栏重复行；810 栏书上
  无 d₁ 列，存 None。
- 选定后 `交付串(品名, 标准号, 规格, 表号, 印刷页)` 出明细表串。

## 边界与勘误

- 全章 6 页（印刷 62~67）页顶均无「续表」，**8 表全部单页不跨页**（E 位核查）；表5-6 与
  表5-7/5-8 同页相邻但以节标题分隔，无续表关系。
- 章名核实：页图 p001 顶印「第五章 轴系零件的紧固件」；小节结构 一、挡圈（表5-1~5-5）、
  二、圆螺母（表5-6）、三、圆螺母用止动垫圈（表5-7）、四、轴上固定螺钉用的孔（表5-8）。
- **照书存疑①**：表5-4 d₁=10 行「轴 d₄≤」书印 3.3，小于 d₁=9 行的 3.7（非单调）——
  照书存 3.3，断言按书。
- **照书存疑②**：表5-7 带 * 规格（25*/35*/40*/50*/55*/65*/75*）轴端 t 列书印「—」→
  None；55* 行的 d 照书为 56（非 55.5）。
- 「—」与空白格一律存 None：表5-1 d=20/25 的 (0)2 系列无此档、表5-3 L 列轴径 14/16/18、
  表5-8 d=3/4 与 24 列空白等，均不编值。
- 建库方式：L1 由 `handoff-ch05/B1.json+B2.json` 经 `convert_ch05.py` 机械转换（零抄写），
  断言含「模块 dict 与 JSON 逐格等值」体检；B 位表值核读与整合分两次任务、token 分开记账。
