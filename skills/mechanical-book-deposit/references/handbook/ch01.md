## 设计会问 → 答案 → 出处

### 1. 算出来的轴径/长度，怎么取标准值？

```python
from std_data_ch01 import 标准尺寸向上取, 优先数最近值
标准尺寸向上取(33.7, "R′40")   # → 标准值 34（化整值系列）
优先数最近值(33.7, "R40")      # → 33.5
```

- 表1-14（p.11，GB/T 2822—2005）：三个尺寸段块（2.5~37.5 / 40~265 / 280~1900）×
  R10/R20/R40（优先数）与 R′10/R′20/R′40（化整值）6 列，**阶梯状排版**——每列独立
  从上往下读，行对齐无跨列含义，故 rows 只是序号。
- **R5 未单列**（R5⊂R10 但书上没给成员判定），不推；系列超出最大值抛 ValueError。
- 档内不插值，与全书约定一致。
