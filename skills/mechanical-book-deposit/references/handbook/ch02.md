### 1. 某牌号的力学性能全套哪里查？

```python
from material_ch02 import 材料性能
材料性能("45")        # → [表2-7 优质碳素结构钢]：正火850/淬火840/回火600，Rm≥600、ReL≥355、
                      #    A≥16、Z≥40、KU2≥39、交货硬度未热处理≤229/退火≤197 + 应用举例全文
材料性能("QT500-7")   # → [表2-4 球墨铸铁]：Rm≥500、Rp0.2≥320、A≥7、HBW 170~230 + 用途
材料性能("HT150")     # → 表2-3 三项（按铸件壁厚 2.5~10/10~20/20~30 分行，性能随壁厚变）
材料性能("Q235")      # → 表2-6 四项（质量等级 A/B/C/D 各一行，带等级标注）
材料性能("H68")       # → 表2-18 拉制棒材 + 表2-19 板材（一格多牌号格逐行匹配，状态×规格分档）
```

- **多表命中全收、不合并口径**：返回 list，每项带 表号/页/牌号（原样）/性能 dict。
  45 只在表2-7（表2-23 价格比口径不入本函数）；5A05 跨表2-20（棒材）与表2-21（板带）。
- 覆盖 14 张牌号锚定表：2-3 灰铸铁、2-4 球墨铸铁、2-5 铸造碳钢、2-6 碳素结构钢、
  2-7 优质碳素结构钢、2-8 弹簧钢、2-9 合金结构钢、2-10 非调质钢、2-17 铸造
  铜/铝/轴承合金（一表三标准，带「标准分块」标注）、2-18/2-19/2-20 铜铝材、
  2-21 铝板带、2-22 工程塑料（行标签=品种）。
- 查不到 → `ValueError`（列全部可查表号）；同表重复行标签（壁厚/等级/状态分行）每行一项。

### 3. 按强度选钢 / 热处理推荐？

```python
from material_ch02 import 按强度选钢, 热处理状态, 交付串
按强度选钢(950, "表2-9")   # → {'表2-9': [40Cr 980, 20CrMnTi 1080, 20CrMnMo 1180, …]}
按强度选钢(600)            # → 逐钢表各报一组（dict 键=表号），不跨表混口径
热处理状态("40Cr")         # → 表2-9：淬火 850 油 / 回火 520 水、油
热处理状态("60Si2Mn")      # → 表2-8：淬火 870 油（合并大格回落）/ 回火 440
交付串("45", "GB/T 699—2015", "表2-7", 27)
                           # → '45 GB/T 699—2015（表2-7，p.27）'，可直接写进说明书
```

- **按强度选钢只在表2-5~2-10 六张钢表内比**（铸铁/铸造合金/有色/塑料不参与）；
  Rm 取书载下限口径（'375~460' 取 375、'≥590' 取 590——该列本身即「不小于」值）。
- 热处理只认 表2-7（推荐热处理）/2-8（热处理温度）/2-9（热处理）三表；
  「未热处理」交货硬度列不混入热处理 dict。

## 边界与勘误

- **硬度换算一律不做**：`硬度换算()` 抛 `NotImplementedError`——各表 HBW/HRC/HRR 口径
  独立照书并列，书上无换算表。
- **同牌号多表不合并**：45（表2-7 力学性能 vs 表2-23 价格比）、Q235（表2-6 vs 表2-23）、
  40Cr（表2-9 vs 表2-23）、5A03/5A05（表2-20 棒材 vs 表2-21 板带）各按表独立口径；
  表2-23 价格比为转置表（材料沿列向），只出 L1。60Mn（表2-7）与 65Mn（表2-8）勿混。
- 勘误（E 位实核，2026-10-25，详见 `handoff-ch02/E.json`）：**跨页实为表2-7（27→28）与
  表2-9（29→30）**，清单把续表页误挂在表2-8/2-10 名下（continuous 字段系统性误标），
