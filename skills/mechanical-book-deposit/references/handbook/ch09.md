## 画图时会问 → 答案 → 出处

### 1. φ40H7/k6 的上下偏差？什么配合？

```python
from tolerance_ch09 import 配合偏差, 配合标注, 偏差标注
配合偏差(40, "H7", "k6")
# 孔 +25/0 μm，轴 +18/+2 μm，最大间隙 23 μm，最大过盈 18 μm → 过渡配合
配合标注(40, "H7", "k6")      # "φ40H7/k6"
偏差标注(40, "+0.025", "0")   # "φ40+0.025/0"
```

- H7 查表9-6（p.117）>30~40 行：+25/0；k6 查表9-5（p.114）>30~40 行：+18/+2。
- 配合性质判据：孔下 ≥ 轴上 → 间隙；孔上 ≤ 轴下 → 过盈；否则过渡。
- 常用值：φ55k6 = +21/+2；φ100H7 = +35/0；φ80H7 = +30/0；
  φ60r6 = +60/+41；φ42r6 = +50/+34；φ28r6 = +41/+28。


- 表9-9 直线度/平面度；表9-10 圆度/圆柱度；表9-11 平行度/垂直度/倾斜度；
  表9-12 同轴度/对称度/圆跳动/全跳动。
- 只摘录 5~12 级；图上比表内最精级还严的值（如 0.008）属表外，不判图错。
- 表值是 μm；图上 mm 值要 ×1000 后比。
