## 设计会问 → 答案 → 出处

### 1. 给定转矩选联轴器（8 张规格表各一个函数，最小够用档）？

```python
from coupling_ch08 import (凸缘联轴器, 弹性套柱销联轴器, 弹性柱销联轴器, 梅花形联轴器,
                           滑块联轴器, 齿式联轴器, 滚子链联轴器, 带制动轮弹性套柱销联轴器)
凸缘联轴器(500)            # → GY6/GYS6/GYH6 族：900 N·m、6800 r/min、孔径 38 与 40,42,45,48,50
凸缘联轴器(400)            # → 边界归 GY5 族（公称转矩恰 400，最小够用档）
弹性套柱销联轴器(225)      # → LT6 355/3800（LT5=224 不够；Tn=224 时归 LT5）
梅花形联轴器(800)          # → LM170 1250/4500（按公称转矩 Tn，不用最大转矩 Tmax）
齿式联轴器(5000)           # → GICL4 5000/5400
滚子链联轴器(630)          # → GL7 630；转速双列 630(不装罩壳)/2500(装罩壳)
带制动轮弹性套柱销联轴器(1120)  # → LTZ4 1120
滑块联轴器(500)            # → WH6 500/3800
```

- 语义：**公称转矩 ≥ Tn 的最小档**，档内不插值不外推；超全表上限/查不到 → `ValueError`。
- 每项返回 型号、公称转矩、许用转速（全列）、各档明细（孔径档 × Y/J_1 型轴孔长度，merge
  回落）、并列同转矩型号、表号/页/表名。
- **表8-2 型号格是「GY1\nGYS1\nGYH1」三元组合并格**（同规格三变体，跨该族全部孔径档行），
  选型返回格原样；校核转速按行逐个匹配。
- `膜片联轴器()` → `NotImplementedError`：**本章实无膜片联轴器表**（派工令预想，
  实有 8 张联轴器规格表见上）。

### 3. 校核转速？

```python
from coupling_ch08 import 校核转速

校核转速('GL7', 630)    # → 表8-4 双转速列（不装/装罩壳）按最严（小）值比对，全列值随返回
```

### 4. 离合器（按实有，无 Tn 列）？

```python

离合器('简易传动用矩形牙嵌式')        # → 表8-10 全部 5 档
离合器('简易传动用矩形牙嵌式', 40)    # → 按轴径 d 过滤 → 1 档（D=100）
离合器('矩形、梯形牙嵌式')            # → 表8-11 全部 11 档（无 d 列，给 d 报 ValueError）
```

  成立，不做；类型名只有上述两个。

## 边界与勘误

- **换算一律不做**：`转矩换算()`、`工况系数()` 抛 `NotImplementedError`（各表转矩均照书
  以 N·m 给出；工况系数 K_A 在其他章）。
- **派工令预想 vs 实有**：膜片联轴器、十字轴万向联轴器、安全/离心离合器本章实无表；
  实有为 凸缘(8-2)/齿式(8-3)/滚子链(8-4)/弹性套柱销(8-5)/带制动轮(8-6)/弹性柱销(8-7)/
  梅花形(8-8)/滑块(8-9) + 牙嵌离合器 2 表。L2 按实有适配。

  实在 p.101**（清单 pages 原为空）；印刷 100/101 非空页（表8-4/8-5 在），不是续表、不是
