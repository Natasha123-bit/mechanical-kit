## 0. 任务

把 `<书PDF>`（<总页数> 页扫描版，教材）按章沉淀成可计算的公式库 + 表字典 + 断言集，供以后做题时直接调用。

- 章边界：`<工作目录>/章节地图.md`，有冲突以页图页眉为准，并把修正写进 `handoff-chNN/E.json`。
- 你的产物：`~/.hermes/lib/mdkit/lib/<book>/xxx_chNN.py` 与 `xxx_chNN_tests.py`，中间产物 `handoff-chNN/`。

## 1. 每章怎么做

先交 `handoff-chNN/00-清单.json`：把本章**编号式、表、例题**的完整清单列出来（式号、表号、页、例题号），这是后面所有子任务的地基；清单不全不许往下走。

然后分五个子任务（每个可用独立子代理）：
- **A 公式**：`eqNN_<式号>(参数)`，一条编号式一个函数，返回标量或 namedtuple；docstring 写「式(xx-x) 含义 + 适用条件 + 参数 + 返回 + `[核:p.NNN]`」。
- **B 表值**：`表NN_<表号>_<表名> = {"表号","表名","页","单位","rows","cols","data","注"}` + `查表NN_<表名>(...)`；跨页续表合并并注明；原表破折号/空白存 `None` 并在 `注` 里写清有几处。
- **C 断言**：`xxx_chNN_tests.py`，只用 `assert` + 容差，覆盖每条编号式的典型值与边界；跑完打印「合计：通过 N 项，失败 0 项」。
- **D 例题复核**：本章每个例题逐项复算，写 `references/chNN-<主题>-formulas.md` 的对比表（书值 / 库值 / 偏差 / 备注）。
- **E 边界勘误**：章首章末页对不对、有没有混进别的章/篇的页，写 `handoff-chNN/E.json`。

## 2. 零猜测红线（违反即返工）

- 公式符号核不到位置：`raise NotImplementedError("待核：式xx-xx，p.NNN")`，**不许**用通用教材知识补齐。
- 表值核不准：写 `None`，**不许**插值、不许照相邻行推断；`注` 里说明原因。
- 页码一律以页图页眉为准；OCR 文本里的页码只作参考。
- 不确定就写「不确定」，不许编。

## 3. 禁止事项

- 不改、不删、不移动 `<知识库>/raw/` 下任何文件。
- 不动已验收章的库文件；不改别人的 `xxx_chNN.py`。
- 不装新依赖；解释器只用 `~/.local/bin/python3.12` 或 `/usr/bin/python3`。
- 模型白名单：`deepseek-v4.1-flash`、`gemini-3.8-flash-low`、`gemini-3.8-flash-medium`、`gemini-3.8-flash-high`、`deepseek-flash`。**其他一律不许调**。

## 4. 批次与状态（最重要）

- 按批次做，一批 3 章，顺序：<批1 chN,M,K / 批2 ...>。
- **每批做完必须停下**，输出该批小结（章、编号式数、表数、断言数、双解释器结果、未核项），然后等我说「继续」。**不许自己往下一批跑。**
- 进度表状态只许写三种：`未开始` / `进行中` / `待验收（自检已过）`。**「已验收」只能由验收方写**，你写了会被改回去。
- 自检必须真跑：`~/.local/bin/python3.12 xxx_chNN_tests.py` 和 `/usr/bin/python3 xxx_chNN_tests.py` 都要 exit 0，把断言数写进进度表。

## 5. 批量 OCR（如果需要你自己处理新页）

`~/.hermes/lib/mdkit/bin/ocrbox 某页.png` 直接输出 `x y w h 文本`（67 KB 独立二进制，只依赖 macOS）。先试跑一页确认能执行，再批量。**不要用模型逐页抄书**：慢、贵、每次结果不同，无法复现。表格窄列漏识时用 `sips -c` 裁出该列放大 2 倍再 OCR。

你交出的每章，我会亲自做三件事：双解释器跑你的断言、逐格比对表值、用你的库函数复算书上例题。
任何一项对不上都会被退回，并且退回原因会落到验收记录里。
