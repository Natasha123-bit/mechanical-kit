# 机械零件矢量制图章程（drawing 模块）

版本 1.0　·　2026-10-28　·　条款 145 条

> 本文件是 `lib/drawing` 的章程，对模块内的生成器、校验器与交付物有约束力。
> 条款的机器可读形式是 `charter/rules.json`；本文件由 `charter/build_charter.py` 生成，
> 不要直接改本文件——改 `rules.json` 后重跑生成器，再用 `charter/check_charter.py` 校验一致性。

## 0　条款状态与约束力

每条条款有一个状态，标在条款 id 之后：

| 标记 | 含义 | 交付时的处理 |
|---|---|---|
| `[A]` | 有自动检查 | 检查不通过即不得交付 |
| `[M]` | 本质上需要人工判断 | 必须有人签字，并在自检记录里写明依据 |
| `[X]` | 已规定，但当前没有自动检查 | **不得声称已符合**；必须人工核，并在自检记录中标“未自动检查” |

当前覆盖率：**A 47 条（32.4%）／ M 20 条 ／ X 78 条**。

这个比例是事实，不是目标。任何“本章程已全部落实”的说法，都必须先把 X 清零；
在此之前，交付物只能声明“按本章程人工核对，自动检查覆盖 32.4%”。

条款等级：**必**（不通过不得交付）／**应**（偏离须在自检记录中说明）。

## 1　总则

本文件约束的是交付物，不是示意图。三条线不能互相顶替：模型决定投影、特征关联决定标注、纸面尺寸决定版面。检查的价值在于“能报出错误”，一份从不失败的检查等于没有检查。

- **GEN-01** `X` 必　用程序化矢量绘图生成正式工程图，不用图像生成模型绘制需要精确尺寸、公差与文字的图
- **GEN-02** `M` 必　先核对输入结构，再确定表达方案；不先摆版式后补结构
- **GEN-03** `X` 必　所有视图、断面、尺寸与技术要求在生成时引用同一份最终参数
- **GEN-04** `A` 必　几何投影、特征关联标注、纸面排版三层分开管理，不互相顶替
- **GEN-05** `A` 必　使用工作库前核对当前签名、实现与输出，不把函数名当作标准符合性证明
- **GEN-06** `A` 必　分开检查“该线应否存在”（画法）与“线是否在预定位置”（实现），两者都要通过
- **GEN-07** `X` 必　每次修改后重新生成并检查当前版本，不用旧截图判断新图
- **GEN-08** `X` 必　不以缩小文字、遮盖轮廓或删除必需视图来消除布局冲突
- **GEN-09** `M` 必　输入几何不成立时记录具体冲突；需改设计的先按授权同步源数据，不在图上偷改数值
- **GEN-10** `A` 必　未执行或未覆盖的检查写“未检查”，不把空错误列表解释为全部合格

## 2　输入清单

出图前把输入钉死。缺关键输入就停下问，不猜。参考图只借表达方法，它的尺寸、材料、配合与当前零件无关。

- **IN-01** `X` 必　出图前建立输入清单：零件身份、实体结构、空间关系、尺寸含义、精度要求、其他要求、图纸要求、依据
- **IN-02** `X` 必　关键输入缺失时不猜测补齐；只缺署名、单位等非几何字段可留空
- **IN-03** `M` 必　不把“通常有中心孔”“一般用这种配合”转化为实体特征，也不把相邻零件特征画到本零件上
- **IN-04** `X` 必　参考图只迁移适用的表达方法与版式，不携带参考零件的参数
- **IN-05** `X` 应　每项关键输入记录来源与状态：已确认 / 待确认 / 推导值

## 3　标准依据

标准先于画法。三类内容必须分级：标准表达规则、绘图实现约定、某次图样的选择。历史经验、旧库说明、某渲染器的缺陷都不是标准。

- **STD-01** `M` 必　按任务要求的的标准体系核对图幅、比例、字体、图线、视图、尺寸、几何公差、表面结构与标题栏
- **STD-02** `X` 应　依据为教材时记录书名、图表号与印刷页；PDF 物理页映射单独登记，不跨书套用页码偏移
- **STD-03** `M` 应　易误判的表达先看同类结构原图局部，列出可见边、不可见边、剖切边与省略规则再画
- **STD-04** `X` 必　区分三类内容：标准表达规则、绘图实现约定、某次图样的选择
- **STD-05** `M` 必　不把历史工作库说明或某渲染器的缺陷推广成“所有图都只能这样画”

## 4　唯一几何模型

六层数据，一个 feature_id，三种坐标。翻转只在输出层做一次——翻转两次的图看起来“都对”，但每个坐标都是错的。

- **MDL-01** `X` 必　数据分六层：part、geometry、precision、views、layout、checks
- **MDL-02** `A` 必　每个实体特征有稳定 feature_id
- **MDL-03** `X` 必　每个尺寸记录被测要素、测量方向、数值来源与控制/参考属性
- **MDL-04** `X` 必　同一结构只有一份参数，主视、端视、断面与尺寸文字均由它生成，不另存数值副本
- **MDL-05** `X` 必　模型坐标、图纸坐标、渲染坐标分开管理，明确原点与轴向
- **MDL-06** `X` 必　y 轴翻转只在输出层做一次，不在几何层与核查层重复翻转
- **MDL-07** `X` 必　纸面字高、箭头大小、线宽与标注间距独立管理，不随零件整体缩放
- **MDL-08** `M` 必　功能分区不是实体台阶：同一公称直径上的精度差异用范围表示、区段字母或局部要求表表达

## 5　视图与剖切

先写表达方案再画线。剖视图与断面图不是同一种东西；槽口朝向由特征方向与观察方向算出来，不由版面空白决定；剖切必须真的穿过特征。

- **VIEW-01** `M` 必　每个视图先登记名称、类型、观察方向、需表达特征、比例及与其他视图的对应关系
- **VIEW-02** `M` 应　视图数量以清晰完整表达结构为准，不为凑“三视图”增加重复视图，也不省略必要局部结构
- **VIEW-03** `X` 必　区分剖视图与断面图，不把所有含剖面线的图统称“剖面”
- **VIEW-04** `M` 必　断面特殊情形（剖切平面过回转面孔或凹坑轴线、非圆孔使断面分离）按规定保留应有线条
- **VIEW-05** `X` 必　投影法统一，基本视图满足长对正、高平齐、宽相等；第一角俯视图在下、右视图在左
- **VIEW-06** `X` 必　投影法识别符号按标准图例绘制，第一角为圆台侧形在左、同心圆在右、侧形左小右大
- **VIEW-07** `A` 必　槽口朝向由真实特征方向与剖切观察方向推导，不由版面空白决定
- **VIEW-08** `A` 必　剖切位置线、箭头、字母与断面/剖视图名称一一对应；箭头方向不得为让位而反转
- **VIEW-09** `A` 必　剖切平面实际穿过要表达的特征；断面直径、槽宽、槽深取自该位置实体
- **VIEW-10** `A` 必　主视投影为与轴线对中的长圆，仅适用于正对封闭圆头槽的情形
- **VIEW-11** `X` 必　断面缺口处不得残留穿过槽口的完整外圆，也不得填剖面线
- **VIEW-12** `A` 必　台阶竖线是否通长先判断可见性与视图类型，不统一画成通长或两小段
- **VIEW-13** `A` 必　轴、键、紧固件、肋、轮辐、螺纹、齿轮、花键、轴承按规定画法逐项核对条件
- **VIEW-14** `A` 必　同一零件的剖面线方向与间距一致，线族不穿越孔槽，必要时选标准允许的其他角度

## 6　几何成立性

圆角是几何不是装饰：要有切点、圆心、半径，端点要连、切线要连。倒角要截短原边界，不是往尖角上叠两条斜线。极限公差下画不出来的圆角，名义图上再漂亮也是废图。

- **GEO-01** `A` 必　圆角为与相邻表面相切的圆弧，保存切点、圆心与半径
- **GEO-02** `A` 必　圆角构造后核对端点连接与切线连续，不用折线拐弯或遮盖矩形伪装
- **GEO-03** `X` 必　倒角处原端面与母线在倒角端点截短后再连斜线，不在尖角上叠两条斜线
- **GEO-04** `A` 必　开放圆弧不用会自动闭合的多边形图元，否则出现连接两端的额外弦线
- **GEO-05** `A` 必　圆弧扫角核对起点、终点、圆心、切线与极值位置，不只确认半径
- **GEO-06** `A` 应　完整圆优先用圆图元，不用起终点重合的单段圆弧表达
- **GEO-07** `X` 必　直角轴肩四分之一圆内圆角满足 R_max ≤ h_min，h_min 按大径最小与小径最大计算
- **GEO-08** `X` 必　同一短段两端均有过渡时，两侧实际切线占用之和不超过可用长度
- **GEO-09** `X` 必　槽端、孔边、退刀槽与肩圆角的最小净距按最不利公差组合检查

## 7　幅面、线型与字体

幅面按完整包络选，线型按语义分配，字高是纸面约束。粗细分档、点画线节距、中心线出头的目的是让图能读，不是凑格式。

- **SHT-01** `X` 必　按完整图面包络选择幅面：先预留图框、标题栏、技术要求、参数表、尺寸带与视图间距
- **SHT-02** `X` 必　图框边距随幅面与装订形式取自同一套规则，不混用不同幅面的边距
- **SHT-03** `A` 必　不把简化标题栏冒称为完整标准式标题栏
- **SHT-04** `X` 必　比例取自适用标准比例系列，并在标题栏及需要处标明
- **SHT-05** `A` 必　不得非等比拉伸图形；尺寸数字始终表示真实尺寸而非纸上测量值
- **SHT-06** `A` 必　线型按语义分配：可见轮廓与移出断面轮廓粗实线、尺寸与剖面细实线、轴线细点画线、必要时细虚线
- **SHT-07** `A` 应　粗细分档采用一致组合（通常约 2:1），具体按所选标准与图幅确定
- **SHT-08** `X` 应　中心线适当伸出轮廓，圆心位置以长画相交；短范围点画线核对实际节距
- **SHT-09** `X` 必　线型重合按标准优先次序表达，不把不同线型无条件叠加
- **SHT-10** `A` 必　汉字用仿宋体且不低于允许字高；上下偏差可用较小字号，但不得用于整段技术要求
- **SHT-11** `X` 必　font-size 不等于字形墨迹高度，核对所用字体的字面、字宽与实际打印效果
- **SHT-12** `X` 必　空间不足时加宽单元格、换行或重排，不让自动缩字把文字降到下限以下
- **SHT-13** `X` 必　标题栏空白字段可保留，不编造署名、审核记录或单位名称

## 8　尺寸与公差

一个尺寸要能回答：从哪量到哪、界线在哪、终端是什么、数字属于谁。公差不是标签，是从一个对象搬到另一个对象就会变义的东西。

- **DIM-01** `A` 必　每个尺寸核对五要素：测量起止要素、尺寸界线、尺寸线、终端符号、尺寸文字
- **DIM-02** `X` 必　模型尺寸链自洽，但总长与全部分段不同时作为互相重复的独立约束
- **DIM-03** `A` 必　尺寸界线从真实被测要素或其允许延长处引出，不从任意轴线或空白点起算
- **DIM-04** `A` 必　尺寸界线按规则越过尺寸线，延长方向由“远离被测要素”求得，上下侧符号不写反
- **DIM-05** `X` 应　尺寸线、箭头与文字按同一种标注方法统一布置，竖向数字的阅读方向与位置一致
- **DIM-06** `A` 必　直径、半径、槽宽、余厚与深度各有正确标识、终点与引注方式；漂浮文字不能冒充直径标注
- **DIM-07** `X` 必　狭窄处用标准允许的外置箭头、引出文字或延长段，文字外置后仍能辨认所属尺寸
- **DIM-08** `A` 应　尺寸线避免与轮廓、中心线重合；必要交叉按标准处理
- **DIM-09** `A` 必　文字与公差数字不被轮廓线、中心线、引线或箭头穿过
- **DIM-10** `X` 应　尺寸集中在表达该结构最清楚的视图，不在多视图重复给同一独立控制尺寸
- **DIM-11** `X` 必　尺寸公差、配合、几何公差与表面结构分别管理；键槽与轴、槽深与余厚不是同一受控对象
- **DIM-12** `X` 必　槽深改注余厚时偏差符号反转；有独立直径偏差时按 q_min=d_min−t_max、q_max=d_max−t_min 推导
- **DIM-13** `X` 必　上下偏差叠排、位置明确，不用斜杠写成含糊文字串；宽度计算含整个组合
- **DIM-14** `X` 必　一般尺寸公差不自动代替几何公差；已单独给定的公差不被总注覆盖；圆角倒角的未注公差单独核对
- **DIM-15** `A` 必　基准符号连接位置表达设计所指要素；圆柱面导出轴线基准与直径尺寸线对齐，不用随便指向外圆的引线冒充
- **DIM-16** `A` 应　共同基准与主次基准体系按各自框格写法，不互相替代
- **DIM-17** `A` 必　形状公差不引用基准；跳动等按定义引用适当基准；公差值前是否加直径符号取决于公差带形状
- **DIM-18** `X` 必　径向跳动指向被控回转表面，端面跳动指向端面
- **DIM-19** `X` 必　公差符号使用经核对的矢量形状，不用字体缺字、近似 Unicode 图标或普通箭头替代
- **DIM-20** `X` 必　表面结构符号完整：区分基本、去除材料与不去除材料，方向、接触点、附加横线与参数文字齐全
- **DIM-21** `X` 必　核对符号或引线实际指向的表面；槽侧、槽底、密封带与定位端面不得共用落在空白处的引线
- **DIM-22** `X` 必　局部要求优先于其余表面总注；同一表面不重复标注且不出现互相矛盾的要求

## 9　工作库用法

签名以代码为准，不以文档为准。图元契约只保证“元素是合法的 AST”，不保证投影、尺寸或画法正确——这两件事必须分开验。

- **LIB-01** `X` 必　迁移到其他环境时重新确认路径与接口，不照搬绝对路径
- **LIB-02** `A` 必　图元契约检查的 strict 语义择一统一使用：要么抛异常，要么显式检查返回值
- **LIB-03** `X` 必　剖面线图元接受单个简单多边形并自动闭合；带孔区域需可靠分解或显式区间裁切，完成后核对真实边界
- **LIB-04** `X` 应　尺寸、引线、公差框、表面符号与合并单元格在项目组装层封装，底层仍用库图元
- **LIB-05** `M` 应　确需补正库行为时集中在项目层实现并注明原因，不在 SVG 文本里反复替换孤立坐标
- **LIB-06** `A` 必　底层接口签名以代码生成物为准，不以文档抄写的接口表为准

## 10　字体落地

写着仿宋不等于印出来是仿宋。回退不报错，但会改字宽、压线、缺字。判断依据是渲染后的包围盒与字符覆盖，不是 CSS 文本。

- **FONT-01** `A` 必　只写 font-family 不能证明目标机器实际使用了该字体，回退可能不报错但改变字宽
- **FONT-02** `M` 应　记录字体来源、字体名与授权条件
- **FONT-03** `X` 必　单文件 SVG 优先嵌入经过验证的字体；使用外部字体时随图交付并验证引用路径
- **FONT-04** `X` 必　渲染前等待字体就绪，核对资源加载状态与所需字符覆盖；单独调用字体检查不足以排除回退
- **FONT-05** `A` 必　检查中文、直径符号、正负号、上下偏差与长连接号是否缺字或被替换
- **FONT-06** `X` 应　子集化后核对字符映射、字形与 advance width，不手工重写字体表
- **FONT-07** `X` 必　对实际渲染文字取包围盒，不用“中文一字宽等于一字号”的估算

## 11　排版

先预留区域，再放引线。视图的占用区包含它的标注包络，否则“没相交”也会被读成“同一根线”。

- **LAY-01** `M` 应　布局按序执行：固定图框标题栏 → 预留技术要求与表格 → 放视图 → 分尺寸带 → 留公差基准空白区 → 布引线 → 放表面符号并重算包络
- **LAY-02** `A` 必　视图占用区域包含中心线伸出段、剖切标注、尺寸界线、箭头、公差框与文字
- **LAY-03** `A` 必　标题栏等区域设禁入区，其他视图及其中心线、界线不得侵入
- **LAY-04** `A` 必　视图之间保留明确净距，避免未相交却被读成同一根连线
- **LAY-05** `X` 应　界线共用的前提是共线、线型相同、语义兼容且连续段适合合并
- **LAY-06** `X` 必　不对所有同坐标线条做无条件合并

## 12　图元身份

每个图元要能回答：我属于哪个特征、哪个视图、什么角色、依据哪份数据。没有身份，检查器只能靠几何猜；靠猜的检查从未抓住过真正的错。

- **ID-01** `A` 必　图元携带四项身份：feature_id、view_id、role、source，并在输出中留存稳定标识
- **ID-02** `A` 必　检查器按角色筛选目标，不用“所有斜线都是剖面线”“所有细长线都是尺寸线”这类猜测
- **ID-03** `A` 必　不靠数图元判断结构完整：数量正确仍可能漏一条孔口线并多一条错误弦线

## 13　自检四层

画法、几何、碰撞、目视四层各管一件事。模型与输出必须分别核对来源——同一段错误代码生成的两个结果互相一致，什么也证明不了。

- **CHK-01** `M` 必　第一层画法与语义审查：视图是否足够、观察方向是否一致、可见边应否存在、符号是否控制正确对象、尺寸是否足够加工检验
- **CHK-02** `A` 必　第二层几何检查：段连续性、总尺寸、孔槽位置与归属、各视图对应量、真实比例、圆弧与倒角拓扑、极限成形、必需边界与符号存在性、剖面线区间
- **CHK-03** `A` 必　输入模型与输出图分别核对来源；只比较同一段错误代码的两个结果不能发现上游错误
- **CHK-04** `A` 必　第三层碰撞六类：文字—文字、文字—图形、标注—标注、视图—视图、图元—图框、重复线
- **CHK-05** `X` 必　相交不都错误：轮廓连接、箭头触目标、剖面线止于边界、中心线交轴心等按角色与位置识别，不为清零删合法线
- **CHK-06** `A` 必　文字包围盒必须乘根变换矩阵，只读 getBBox 的 x/y/w/h 会漏掉旋转与分组变换
- **CHK-07** `A` 必　实心箭头、基准三角形等填充区域做区域相交与包含检查，不只查边线
- **CHK-08** `X` 必　检查器只处理部分图元类型时，必须明确写出未自动覆盖的类型
- **CHK-09** `M` 必　第四层：整页与放大局部同时复核（主视、关键台阶、断面、密集公差区、表面符号、技术要求、标题栏）
- **CHK-10** `M` 必　视觉审阅不承担精确读数；数值与线位以模型、SVG 文本、坐标与校准后的像素探针核对

## 14　可复现渲染

物理尺寸、viewBox、像素映射都要写死并量出来。版本靠哈希绑定，不靠修改时间。

- **RUN-01** `X` 必　渲染按序执行，任一步失败即停止依赖它的后续步骤
- **RUN-02** `X` 必　SVG 根节点显式写物理尺寸与对应 viewBox
- **RUN-03** `X` 必　像素核查前标定图面原点、裁切范围与横纵比例，检查 kx 与 ky 是否一致以排除非等比缩放
- **RUN-04** `X` 应　像素探针避开中心线、交点、箭头与无关文字，并计入线宽与抗锯齿
- **RUN-05** `X` 必　稀疏白点只证明那些点留白，不能证明整个槽区没有误填线
- **RUN-06** `X` 必　每次生成记录输入、脚本、字体、依赖、SVG 与预览摘要、时间及渲染器版本
- **RUN-07** `X` 必　预览与 SVG 以哈希绑定；单列两个文件哈希不能证明预览来自该版 SVG
- **RUN-08** `X` 必　修改字体、线型或文字位置后，之前的碰撞结论随之失效
- **RUN-09** `X` 应　PDF 仅在需要时转换，明确纸张方向与零边距，核对页数与实际页面尺寸

## 15　检查器自检

给检查器喂错误，看它报不报。只跑相关用例，但关键用例必须能抓住。注错证明的是“检查器看得见”，不是“图画对了”。

- **MUT-01** `X` 必　在临时副本中注入错误验证检查器识别能力：错向槽口、穿字、删箭头、残留整圆、错值文字、不可成形圆角
- **MUT-02** `M` 应　只运行适合本次变更的检查，不重复跑无关的大量用例
- **MUT-03** `M` 必　注错用于证明检查器有识别能力，不代替标准画法审查

## 17　交付门禁

下面 15 项逐条写 通过 / 不通过 / 不适用 / 未检查。必需项不通过或未检查时，不得标记为正式完成版。

- **GATE-01** `A` 必　输入结构、技术要求与图纸版本已确认，没有夹带其他零件的数据
- **GATE-02** `X` 必　实体、精度、视图、布局分层，所有视图与标注引用同一最终模型
- **GATE-03** `X` 必　视图数量足够，投影法、观察方向、剖切方向及比例一致
- **GATE-04** `M` 必　外视、剖视、断面及特殊规定画法已分别核对
- **GATE-05** `X` 必　轮廓无错误闭合、缺边、额外弦线或不存在的实体特征
- **GATE-06** `X` 必　圆角、倒角及相邻特征在规定极限尺寸下可成形
- **GATE-07** `X` 必　尺寸足以定义结构，不重复独立约束，起止要素明确
- **GATE-08** `X` 必　公差、基准、表面结构及技术要求指向正确对象，无互相矛盾
- **GATE-09** `X` 必　线型、字高、箭头、图框及标题栏符合所用规则
- **GATE-10** `X` 必　字体实际加载，所需字符完整，文字未被自动缩到下限以下
- **GATE-11** `X` 必　文字碰撞、标注冲突、局部重复线、越界及禁入区均已检查
- **GATE-12** `X` 必　剖面线止于实体边界，孔槽与规定不剖区域没有误填
- **GATE-13** `X` 必　最终 SVG 已解析，当前预览已渲染，二者与核查记录版本相符
- **GATE-14** `M` 必　整页及关键局部已复看，自动检查未覆盖部分有明确处理记录
- **GATE-15** `X` 必　自检结论限定于实际执行范围，没有用程序通过冒充外部认证

## 附录 A　常见错误对照

| 表现 | 根因 | 修正与复查 |
|---|---|---|
| 主视与断面尺寸不同 | 多份参数分别硬编码 | 改为同一特征模型驱动，比较还原后的真实量 |
| 槽口方向不对应 | 未定义视图坐标和观察轴 | 从特征方向向量重新投影，核对剖切箭头 |
| 槽口被完整圆穿过 | 先画整圆后忘记扣除缺口 | 直接生成开口轮廓，检查槽口角区及拓扑 |
| 圆弧多出一条弦线 | 使用自动闭合多边形 | 改用开放圆弧或开放折线，核对端点连接 |
| 名义轮廓可画，公差极限不能成形 | 只检查公称尺寸 | 核查最大圆角和最小台阶、实际净距 |
| 倒角看起来有，但尖角仍在 | 旧端面和旧母线未截短 | 删除不再存在的边段，按真实切点重建 |
| 引线穿字、穿基准框 | 只检查实体外形，没有检查标注包络 | 为文字和框留区，移动整组标注并重检 |
| 偏差数字压尺寸线 | 只给主值计算留白 | 将主值与上下偏差合组计算尺寸 |
| 标题栏横线穿过名称 | 合并格仍输出完整网格 | 按实际单元格边界重建格线 |
| 字体突然变宽或换形 | 静默字体回退或子集字宽损坏 | 核查字体加载、字符映射及实际文字包围盒 |
| 辅助功能带变成实体台阶 | 精度要求混入几何模型 | 将功能区移到精度层，用适用范围表示 |
| 自检零报错，实际仍有圆弧穿字 | 检查器未处理路径 | 补足路径覆盖，未补足前记为未自动检查 |
| 所有线位同时误报 | 坐标重复翻转或截图偏移错误 | 标定根坐标到像素映射后再判断图是否需要修改 |
| 改完后预览仍像旧图 | 渲染失败、缓存或交付版本混用 | 检查执行结果与哈希，重建当前版本预览 |
