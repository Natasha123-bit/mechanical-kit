# 要素清单 features.json —— 让检查器知道"应该有什么"

## 为什么要有这个文件

L0~L3 其余二十四条都以「图上已经画出来的图元」为前提：查它们之间接没接上、撞不撞、
读数对不对。图上压根没有的东西，四层一起沉默。

实测两轮都栽在这上面：

| 项目 | 漏了什么 | 章程当时 | 谁发现的 |
|---|---|---|---|
| 齿轮测试1 | 腹板孔口 4 条竖线 + 远侧可见轮廓 4 条 | 28 通过 0 不通过 | 用户看预览图 |
| 多段轴测试1 | 轴肩阶梯线中段（被"消 T 型接点"的修改砍掉） | 33 通过 0 不通过 | 用户看预览图 |

`L2-10` 用这份清单反向查：**清单说有，图上没有 → 报**。

## 谁生成

生成器（`build_*.py`）。它在几何层已经算出每个要素的坐标，导出这份清单是顺手的事，
不需要从 SVG 反推——从 SVG 反推永远自洽，也就永远查不出漏画。

清单与图必须同源同时：生成器写 SVG 的同时写 features.json，二者用同一批变量。
**不允许事后补写**，那等于把"我画了什么"抄一遍，检查器只能证明"抄得对"。

## 格式

```json
{
  "图号": "CS2-01",
  "比例": 0.5,
  "要素": [
    {
      "id": "seg2.od.up",
      "类型": "线段",
      "视图": "main",
      "说明": "φ61 上母线，到轴肩止",
      "x1": 61.0, "y1": 96.5, "x2": 101.0, "y2": 96.5
    },
    {
      "id": "shoulder.2",
      "类型": "线段",
      "视图": "main",
      "说明": "Ⅱ→Ⅲ 轴肩阶梯线，画满大直径",
      "x1": 101.0, "y1": 91.0, "x2": 101.0, "y2": 103.5
    },
    {
      "id": "circ.A",
      "类型": "圆",
      "视图": "sectionA",
      "说明": "断面 A 的 φ61 外圆",
      "cx": 55.0, "cy": 60.0, "r": 15.25
    }
  ]
}
```

### 字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 唯一标识，报错时用它指认缺口 |
| `类型` | 是 | `线段` / `圆` |
| `视图` | 否 | 只是给人看的标签，检查器不按它分组 |
| `说明` | 否 | 报错时一起打印，便于对照 |
| `x1,y1,x2,y2` | 线段必填 | **图面毫米，坐标与 SVG 同一套（y 向下）** |
| `cx,cy,r` | 圆必填 | 同上 |
| `容差` | 否 | 单条要素的覆盖下限，默认 0.95 |

### 坐标约定

与 SVG 属性同一套坐标（`viewBox` 内的图面毫米，y 轴向下）。不要换算成工程坐标，
也不要乘比例——`Ctx` 里的图元坐标就是这个坐标系，检查器直接比。

## 判据（L2-10）

**线段**：找出图上所有 `data-role` 为 `outline` / `section-outline` / `key-outline`
的线段，投影到清单段的方向上：

- 两端垂直距离都 ≤ 0.15mm 才算共线；
- 投影区间合并（相邻 ≤0.3mm 视为接上——圆角切点处本来就会拆段）；
- 合并后的并集覆盖率 ≥ `容差`（默认 95%）算通过。

覆盖率不足时报出**最大缺口的位置和长度**，不是只说一句"缺了"。

**圆**：找 `circle`，同心（≤0.15mm）同半径（≤0.15mm）即算存在。

**清单里没有的线**不报。清单是"至少要有"，不是"只许有"。倒角和圆角这些
次要图元可以不进清单——少写不罚，写错要罚。

## 缺文件时

没有 `features.json` → `L2-10` 判**未检查**，并在证据里写"没有要素清单，查不了完备性"。

不判通过。CHK-08 的规矩：没自动覆盖的，写出来，不算绿。

## 这一条挡不住什么

- 清单本身写错（比如生成器以为轴肩线只该画到圆角切点）——它照抄了错误的认识，
  检查器只会说"你画的和你以为的一致"。**这一条的效力上限，取决于写清单的人对画法的理解**。
- 圆角、倒角、剖面线、尺寸线不在清单要求范围内（它们由 L2-01~L2-09 管）。
- 文字、标注、表格版面不在清单范围内（L1、L3 管）。
