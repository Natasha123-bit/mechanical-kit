# 计算书 JSON 字段契约

检查器不认“任意形状的计算书”。它按这份契约取期望值，取不到就判**未检查**（不是通过）。

章程依据 CHK-03：输入模型与输出图必须分别核对来源，只比较同一段代码生成的两个结果
发现不了上游错误。所以计算书要独立于绘图脚本产生，字段名按本文件写死。

## 顶层

一份 JSON 对象。检查器目前只读下面两段，其余字段随便放，不会报错也不会用到。

## `键` — 供 L1-09（键槽宽/槽深与计算书一致）

```json
"键": {
  "许用": 100.0,
  "低速轴齿轮": {
    "位置": "低速轴齿轮",
    "d": 50, "b": 14, "h": 9, "t": 5.5,
    "L": 100, "l": 86,
    "标记": "键 14×9×100 GB/T 1096",
    "键槽": "44.5-0.2"
  }
}
```

| 字段 | 必填 | 用途 |
|---|---|---|
| `b` | **是** | 键宽，与图上键槽宽尺寸文字逐条比对 |
| `h` | 否 | 键高 |
| `t` | 否 | 轴槽深（`d+t1` 里的 t1） |
| `L` / `l` | 否 | 键长 / 有效长度 |
| `标记` | 否 | 标准标记串，供人工复核 |
| `键槽` | 否 | 毂槽深标注 |

- 方言义键（名称自取，检查器不看名称，只看 `b` 之类的值）。
- 顶层可以有标量（如 `"许用": 100.0`），检查器只挑 `dict` 且含 `b` 的项。

## `材料45` — 供 L1-10（材料与热处理与计算书一致）

```json
"材料45": {
  "材料": "45",
  "热处理": "调质",
  "毛坯直径": "≤200",
  "硬度HBW": [217, 255],
  "σB": 640.0,
  "σs": 355.0
}
```

| 字段 | 必填 | 用途 |
|---|---|---|
| `材料` | **是** | 与标题栏“材料”栏比对 |
| `热处理` | 否 | 检查图上是否出现“调质”等字样 |
| 其余 | 否 | 强度数据，供人工复核 |

## `派生` — 供 `part/shaft.py`（P-01~P-05）与 `part/gear.py`（P-13）

part 层不去猜“这根轴长什么样”，只按段表核图。**段表是唯一入口**，缺了就整层判未检查。

```json
"派生": {
  "总长": 267.5,
  "段界": [0.0, 47.0, 127.0, 144.0, 219.0, 267.5],
  "直径": [55.0, 61.0, 64.0, 71.0, 55.0],
  "半径": [27.5, 30.5, 32.0, 35.5, 27.5],
  "段长": [47.0, 80.0, 17.0, 75.0, 48.5],
  "台阶": [{"肩": 47.0, "左段": "Ⅰ", "右段": "Ⅱ", "d左": 55.0, "d右": 61.0,
            "h": 3.0, "R": 2.0, "平坦面": 1.0}],
  "圆角": [{"肩": 47.0, "R": 2.0}],
  "倒角": 1.0
}
```

| 字段 | 必填 | 用途 |
|---|---|---|
| `段界` | **是**（轴） | n+1 个长度坐标（从 0 起），段 i 占 `[段界[i], 段界[i+1]]` |
| `半径` | **是**（轴） | **n 个**（比 `段界` 少一个）；P-01 核母线、P-05 核断面、L2-14 按段界推台阶覆盖面 |
| `直径` | 否 | 与 `半径` 冗余，供人工核对 |
| `台阶` | 否 | `左段`/`右段` 给出段名（Ⅰ/Ⅱ…），缺省用 Ⅰ~Ⅷ 顺序补 |
| `圆角` | 否 | `[{肩, R}]`，P-03 核圆角半径 |
| `倒角` | 否 | 单个数值，P-01 在两端让步用 |

坐标一律是**零件坐标**（左端为 0），不是图纸坐标；检查器用图上轮廓最左点当 X0 换算。

齿轮的 `派生` 只读标量：

| 字段 | 用途 |
|---|---|
| `d` / `da` / `df` | 分度 / 齿顶 / 齿根圆直径，进 P-13 的直径集 |
| `rim_d` | 轮缘内径（进直径集） |
| `hole_Rc` | 孔分布圆半径，直径集里用 `2×hole_Rc` |
| `输入.几何.b` | 齿宽，进线性集 |
| `输入.结构.bore/hub_d/hub_l/web_t/hole_d` | 轴孔径/轮毂外径/轮毂长/腹板厚/孔直径 |

## `键` 的补充（`part/shaft.py` P-04/P-05 用到的字段）

在原有 `b` 之外，part 层还读：

| 字段 | 用途 |
|---|---|
| `t1` | 轴槽深，P-05 核断面槽底 `cx+r−t1` |
| `槽长` | 键槽全长，P-04 核长圆总跨距 |
| `槽宽带` | 如 `N9`，只在图上比对文字时用 |

## 缺字段时检查器怎么报

- 整个 `键` 段缺失 → `L1-09 未检查：计算书缺 键 段（见 charter/calc.schema.md）`
- `键` 段有但没有含 `b` 的项 → `L1-09 未检查：键 段里没有带 b 的键`
- `材料45` 段缺失 → `L1-10 未检查：计算书缺 材料45 段`
- `派生.段界/半径` 缺失 → `P-01/P-05 与 L2-14 未检查：calc 没有 派生.段界/半径`
- `派生` 里没有任何直径/线性字段 → `P-13 未检查：calc 缺直径/线性尺寸字段`

**不会**因为缺字段判“不通过”——缺输入是未检查，不是图错。

## 为什么不写“万能适配器”

能猜的只有字段名，猜错了就是拿别的题的键去比这张图的键槽，比“未检查”更糟。
所以宁可在契约上加一条，也不让检查器去适配未知形状。

新写一份计算书时，照这份文件写 `键` 和 `材料45` 两段即可；其余内容随便组织。
